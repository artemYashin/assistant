# Ввод чисел

Числовые поля используют общий компонент. Можно выделить число целиком, удалить его и набрать новое: во время редактирования пустое поле не заменяется видимым нулём. Число передаётся форме при вводе; при выходе из поля показывается значение, принятое формой, с её ограничениями и форматированием.

Буквы и посторонние символы не принимаются, в том числе при вставке. В полях целых чисел нельзя вводить дробную часть; дробные значения разрешены там, где они предусмотрены, например в поле «Обновлять тикеты и PR каждые, минут». Для дробной части используйте точку. Экспоненциальная запись не поддерживается.

Минимум, максимум, обязательность и проверки при сохранении остаются прежними. Пустое числовое значение в настройках может преобразоваться в ноль или минимальное допустимое значение согласно правилам конкретного поля. Перед сохранением заполните обязательные поля. Стрелки вверх и вниз и привычные сочетания копирования, выделения и вставки продолжают работать.
