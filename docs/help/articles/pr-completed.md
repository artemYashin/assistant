# Завершённые PR и переимпорт

## Просмотр
Раздел Pull Requests → Завершённые использует заказчика/проект из верхнего хедера, без отдельного селектора репозитория. «Обновить» рядом с заголовком обновляет список. По 20 PR на страницу, за последние 7 дней.
Список запрашивается в Azure. Если PR уже кэширован, описание и связи читаются локально. Если PR ранее импортировался активным, полное описание сохраняется при переходе в завершённые и не заменяется кратким. Ранее неизвестный PR получает описание из ответа списка, которое может быть сокращено.
Срок кэша — семь дней от даты завершения, не от последнего открытия. После истечения архивные локальные данные/связи/ревью очищаются; Azure не удаляется.
## Переимпортировать
Кнопка у завершённого PR показывает confirmation. Подтверждение загружает отдельную полную деталку и актуальные Azure-связи. Затем одной транзакцией заменяет данные карточки и сбрасывает все ручные локальные привязки и отметки «Не учитывать».
Останутся ссылки из полного описания, названия и Azure. Это не массовый импорт самих Work Items. Срок хранения не продлевается относительно даты завершения.
При ошибке загрузки прежний кэш и локальные привязки сохраняются. Если PR перестал быть завершённым/вышел за недельный архив или изменилось подключение, операция отклоняется.
## Большое описание и неверный номер
Обычное «Обновить» не равно полной детализации каждого PR. Для полной версии используйте «Переимпортировать». Приложение сохраняет полученные title/description без локального усечения. Если после переимпорта номер неверный, нужны ожидаемый ID, отображаемый ID и фактическое поле API; нельзя гарантировать исправление одной перестановкой источников.
Log Review показывается только там, где есть лог последнего глобального ревью, а не на каждом архивном PR.
