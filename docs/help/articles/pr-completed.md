# Завершённые PR и переимпорт

## Просмотр

Раздел Pull Requests → Завершённые использует заказчика/проект из верхнего хедера, без отдельного селектора репозитория. «Обновить» рядом с заголовком обновляет список. По 20 PR на страницу, за последние 7 дней.
Список запрашивается в Azure. Если PR уже кэширован, описание и связи читаются локально. Если PR ранее импортировался активным, полное описание сохраняется при переходе в завершённые и не заменяется кратким. Ранее неизвестный PR получает описание из ответа списка, которое может быть сокращено.
Срок кэша — семь дней от даты завершения, не от последнего открытия. После истечения архивные локальные данные/связи/ревью очищаются; Azure не удаляется.

## Переимпортировать

Кнопка у завершённого PR показывает confirmation. Подтверждение загружает отдельную полную деталку и актуальные Azure-связи. Затем одной транзакцией заменяет данные карточки и сбрасывает все ручные локальные привязки и отметки «Не учитывать».
Останутся ссылки из полного описания, названия и Azure. Это не массовый импорт самих Work Items. Срок хранения не продлевается относительно даты завершения.
При ошибке загрузки прежний кэш и локальные привязки сохраняются. Если PR перестал быть завершённым/вышел за недельный архив или изменилось подключение, операция отклоняется.

## Большое описание и неверный номер

Обычное «Обновить» не равно полной детализации каждого PR. Для полной версии используйте «Переимпортировать». Приложение сохраняет полученные title/description без локального усечения. Если после переимпорта номер неверный, нужны ожидаемый ID, отображаемый ID и фактическое поле API; нельзя гарантировать исправление одной перестановкой источников.
Log Review показывается только там, где есть лог последнего глобального ревью, а не на каждом архивном PR.

## Посмотреть PR по номеру

В разделе «Завершённые» введите «Номер pull request» и нажмите «Посмотреть». Поиск обращается в текущую организацию/коллекцию Azure по номеру, независимо от репозитория, статуса и возраста PR. Нужен PAT с Code: Read и доступом к этому репозиторию. Недельный список остаётся отдельным: поиск не ограничен семью днями и не перебирает его страницы.

Результат использует обычную карточку PR: статус «Активен», «Завершён» или «Отклонён», автор, ветки, полное описание, связанные тикеты, «View Diff» и «Коммиты». В diff доступны дерево файлов, подсветка и сравнение; из списка коммитов можно открыть изменения отдельного коммита. Действуют обычные ограничения просмотра больших/исключённых файлов. Ошибка загрузки связей не скрывает сам PR — рядом со связями появляется сообщение.

Известный синхронизированный активный PR открывается в обычном активном разделе со всеми доступными ему действиями и сохранёнными результатами ревью. Для остальных используется просмотр без изменения Azure: запуск ревью, merge, редактирование и комментарии в diff недоступны, пока PR не включён в обычную синхронизацию. Переход из ветки/файла в локальный репозиторий не предлагается для неизвестного репозитория.

«Обновить» повторно читает PR; «Вернуться к списку PR» возвращает недельный список и поле поиска. Недоступный/удалённый PR или неверный номер показывают ошибку на этой странице. После смены подключения откройте PR заново.

Точечный просмотр не импортирует PR в недельный архив, не создаёт мониторинг, не меняет локальные привязки, исключения и результаты ревью. Миграция сохранённых данных не требуется. Снимок и diff хранятся временно в памяти сервера: до обновления карточки, перезапуска сервера или вытеснения после открытия более 32 снимков. При сообщении об устаревшем просмотре нажмите «Обновить». Перезагрузка страницы повторяет поиск по номеру в адресе. Никакого автоматического удаления старых пользовательских PR при таком поиске нет.

## Переход из связанного тикета

Ссылка из «Деталка тикета → Связанные PR» использует ту же карточку с diff и коммитами. Завершённые и отклонённые PR открываются во вкладке «Завершённые», даже если им больше семи дней или их репозиторий не настроен в текущем проекте. Перебирать страницы списка не нужно. Есть кнопка возврата к исходному тикету.

Ссылка привязана к сохранённой деталке тикета и её Azure-подключению. Если подключение сменилось или карточка недоступна, откройте тикет заново. Названия и статусы связей по-прежнему догружаются только при открытии вкладки «Связанные PR»; полный PR — при переходе к нему.

## Сохранённые ревью в точечном просмотре

При открытии завершённого или отклонённого PR из «Связанные PR» либо через «Посмотреть» Orbit также показывает последний сохранённый результат ревью и историю, если этот PR уже известен локально. История доступна при наличии нескольких сохранённых отчётов, как в обычном списке «Завершённые». Сохраняются сведения о модели, токенах, лимите инструментов и комментарии к ревью. Сопоставление учитывает подключение Azure, проект, репозиторий и номер PR.

Если коммиты Azure уже отличаются от проверенных, результат остаётся помеченным как ревью предыдущей версии и ссылается на проверенный коммит. Просмотр не переносит и не перезаписывает отчёты; неизвестному PR не подставляется история другого проекта. После смены подключения временный просмотр нужно открыть заново. Миграция базы не требуется: используются существующие записи ревью.
