# Настройки ассистента и Copilot

## GitHub Copilot
Настройки → GitHub Copilot: подключение аккаунта, при необходимости Client ID, выбор модели чата и модели PR-ревью. Список моделей кэшируется на сутки; он зависит от доступности аккаунту. Подключение Azure PAT не подключает Copilot.
Здесь также лимит ручных PR-ревью за 24 часа. Это количество запусков, не бюджет токенов.
## AI Assistant → Общие настройки
Инструкции ассистенту дополняют поведение, но не отменяют обязательное UI-подтверждение памяти/Teams.
Лимит времени ответа — общий срок запроса (default 180 секунд). Максимум вызовов инструментов — default 30. Порог входных + выходных токенов чата на запрос — default 100 000, не размер полного контекстного окна модели и не месячная подписка.
Когда порог достигнут, ошибка указывает этот раздел настроек. Повышение бюджета увеличивает допустимые затраты; не лечит проблему доступа Azure.
## AI Assistant → Code Repository
«Доступ к коду» включён по умолчанию; при выключении кодовые инструменты не предоставляются. Ожидание подготовки Git — default 20 секунд, 0 не ждать, максимум 120; ограничено также общим временем ответа.
Основная ветка задаётся в настройках репозитория, не здесь. Явная просьба работать в другой ветке переопределяет её.
## Code Review
Лимит токенов ревью (default миллион) и инструментов (default 30) независимы от чата; общий бюджет на всё ревью/продолжения.
## Учёт
Входные токены включают доступный контекст, инструкции и результаты инструментов, которые модель читает; короткая пользовательская фраза не означает маленький вход. Повторные чтения и большой вывод инструментов могут увеличивать расход. SDK-usage может приходить с задержкой/частично; не путайте символы, токены и лимит окна модели.
