# Настройки ассистента и Copilot

## GitHub Copilot
Настройки → GitHub Copilot: подключение аккаунта через «Войти через GitHub» (GitHub CLI с одноразовым кодом), выбор модели чата и модели PR-ревью. Список моделей кэшируется на сутки; он зависит от доступности аккаунту. Подключение Azure PAT не подключает Copilot.
Собственное OAuth-приложение и Client ID больше не настраиваются; ранее сохранённый Client ID игнорируется.
Суточного ограничения количества PR-ревью в Orbit нет. Прежняя настройка убрана; сохранённое значение больше не действует. Лимиты времени, токенов и инструментов отдельного запуска настраиваются в Code Review.
## AI Assistant → Общие настройки
Инструкции ассистенту дополняют поведение, но не отменяют обязательное UI-подтверждение памяти.
Лимит времени ответа — срок запроса чата (default 180 секунд). Максимум вызовов инструментов — default 30. Порог входных + выходных токенов чата на запрос — default 100 000, не размер полного контекстного окна модели и не месячная подписка.
Когда порог достигнут, ошибка указывает этот раздел настроек. Повышение бюджета увеличивает допустимые затраты; не лечит проблему доступа Azure.
## AI Assistant → Code Repository
«Доступ к коду» включён по умолчанию; при выключении кодовые инструменты не предоставляются. Ожидание подготовки Git — default 20 секунд, 0 не ждать, максимум 120; ограничено также общим временем ответа.
Основная ветка задаётся в настройках репозитория, не здесь. Явная просьба работать в другой ветке переопределяет её.
## Code Review
Лимит токенов ревью (default миллион) и инструментов (default 30) независимы от чата; общий бюджет на всё ревью/продолжения.
## Учёт
Входные токены включают доступный контекст, инструкции и результаты инструментов, которые модель читает; короткая пользовательская фраза не означает маленький вход. Повторные чтения и большой вывод инструментов могут увеличивать расход. SDK-usage может приходить с задержкой/частично; не путайте символы, токены и лимит окна модели.

Code Review → Лимиты ревью → «Лимит времени ответа ревью, секунд»: отдельный тайм-аут от 15 до 86 400 секунд, по умолчанию 600. Он включает запуск Copilot, ожидание модели и инструменты одного запроса; подготовка Git и сбор diff выполняются до него. После ответов на уточнения для следующего запроса время отсчитывается заново. Ошибка тайм-аута указывает соответствующий раздел настроек.

При анализе тикета полная деталка, уже прочитанная в текущем запросе, повторно используется инструментами get_ticket и list_tickets(detail=full). Это не постоянный кэш: следующий запрос может снова получить актуальные данные из Azure. Открытие деталки через show_ticket_details передаёт интерфейсу номера тикетов, без загрузки их содержимого в контекст модели.

## Режим работы

«Настройки → Рабочее пространство → Режим работы» определяет видимость локальных поручений и отпусков. В «Разработчик» их инструменты не предоставляются чату; остальные разрешения и лимиты чата/ревью продолжают действовать. Подробности: [Режим работы](work-mode.md).
