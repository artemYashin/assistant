# Статус и исполнитель Azure

## Изменить статус

Откройте редактор статуса тикета или массовую форму, выберите допустимый статус для данного типа задачи. В одиночном редакторе список статусов открывается поверх содержимого, не растягивая окно; длинный список прокручивается внутри. Цвета настраиваются отдельно и не меняют допустимые переходы Azure.
Список типов/статусов кэшируется на 30 дней, с привязкой к подключению и доступу. Смена настроек/учётных данных не должна смешивать каталоги разных подключений. Кэш не гарантирует, что сервер разрешит конкретный переход.

## Изменить исполнителя

Откройте форму Azure-исполнителя, найдите человека по имени/email и выберите однозначную запись. «Не назначен» снимает Azure-назначение. Под ним доступны последние успешно выбранные исполнители — для повторного назначения без нового поиска. Это не список локальных разработчиков.
Сохраняются идентификатор и отображаемые данные выбранного Azure-пользователя, а не его токен.

## Что происходит после изменения

Orbit выполняет изменение в Azure и перечитывает тикет, чтобы актуализировать локальный кэш. Ошибка HTTP не всегда доказывает отсутствие изменения: сервер мог принять PATCH до обрыва соединения.
При неоднозначном результате сначала проверьте фактический статус/исполнителя, не повторяйте запись вслепую. Проверка GET и обновление кэша могут дать отдельную ошибку после успешной записи.
Для записи нужны Work Items Read & write и права пользователя. Устаревшая ревизия, неверное имя статуса, правила процесса и недоступный исполнитель требуют обновления формы/выбора, а не повышения лимита токенов.

## В чате

Явная одиночная смена статуса не требует лишнего подтверждения. Массовая Azure-запись требует плана с точными ID и подтверждения. Локальные метаданные — другой инструмент и не изменяют Azure.

Прочитанные для тикета статусы также попадают в общий локальный каталог типов/статусов. Во вкладке «Заказчики и проекты» → «Автоматический импорт» кнопка «Реимпортировать статусы» обновляет весь каталог по сохранённому подключению, включая статусы всех типов, независимо от фильтра импорта.
