# Инструменты ревью

Ревью использует отдельный экземпляр того же Agent и общие реализации инструментов. Его сессия, контекст, остановка, лимиты и учёт токенов отделены от чата. Чат и одно ревью могут работать одновременно; несколько ревью обрабатываются последовательно. Сервисы и Git-кэш общие: второй клон не создаётся, Git-операции могут кратко ждать своей очереди. Ревью читает зафиксированный коммит PR, а не переключаемую в интерфейсе ветку.

| Инструмент | Назначение и условия |
| --- | --- |
| `read_memory` | Детали записи из выбранного каталога памяти. Краткие названия уже переданы; чужие разделы недоступны. |
| `propose_memory` | Предложение памяти для последующего подтверждения пользователем. |
| `ask_review_questions` | Уточняющие вопросы, если разрешены настройками запуска и не исчерпаны доступные раунды. |
| `code_work_status` | Состояние Git-работ. Только при разрешённом чтении кода. |
| `code_branches` | Поиск/список локально известных веток, при разрешённом чтении кода. |
| `code_tree` | Структура файлов, при разрешённом чтении кода. |
| `code_search` | Поиск по коду, при разрешённом чтении кода. |
| `code_read_file` | Чтение нужных диапазонов файла, при разрешённом чтении кода. |
| `cite_code` | Ссылки на файл и строки проверяемого коммита, при разрешённом чтении кода. |
| `cite_ticket_content` | Цитирование подготовленных требований выбранных связанных тикетов, если их чтение включено. |

Diff, краткий каталог выбранной памяти и разрешённые данные связанных тикетов (включая комментарии и заметки) готовит сервер перед вызовом модели. Это не дополнительные инструменты модели. У ревью нет поиска всех тикетов, инструментов экспорта, редактирования тикетов, чтения картинок по URL или справки приложения. Схемы разрешённых инструментов передаются сразу, без `load_tools`.

Полученные инструментами сведения остаются в сессии этого ревью при переходе между файлами и продолжении после уточнений. Остановка ревью не останавливает чат. В «Использование LLM» активные запросы можно остановить отдельно; устаревшая кнопка не остановит новый запрос. Общие ограничения провайдера всё ещё могут замедлить параллельные ответы.

## Лимиты отдельного запуска

В окне запуска ревью поля «Максимум токенов на ревью» и «Максимум инструментов на ревью» расположены рядом, подписи — над полями. Они подставляются из «Настройки → Code Review → Лимиты ревью». Можно изменить их только для текущего запуска, без изменения общих настроек. Максимум инструментов — число вызовов, а не число разных инструментов; допустимо от 1 до 1000. Токены — входящие и исходящие за всё ревью, допустимо от 1000 до 100000000.

Оба лимита сохраняются с заданием и учитывают продолжения после вопросов. Достижение лимита вызовов останавливает ревью с сообщением: для нового запуска увеличьте «Максимум инструментов на ревью». Уже использованный бюджет при продолжении не обнуляется. Старые сохранённые задания без индивидуального лимита инструментов используют настройку Code Review; существующая история и результаты сохраняются.

## Бюджет и комментарий в результатах

Рядом с токенами в результате и в истории показано «Инструменты: использовано / лимит». Вызовы суммируются по запросам именно этого запуска, включая продолжения после вопросов; очистка подробного Log Review не сбрасывает счётчик. Если данные сохранились лишь частично, это отмечается. Неизвестный расход или исторический лимит обозначается «—»: текущая настройка не подставляется вместо неизвестного прошлого значения. Для старых ещё не начавшихся заданий фактический лимит сохраняется при запуске.

Если при запуске был указан комментарий ревьюеру, в шапке результата есть кнопка «Комментарий». Сам текст не показывается в результате, строке истории или подсказке кнопки. Нажатие открывает отдельный попап «Комментарий к ревью» поверх результата; «Закрыть» или Escape возвращает к результату, а не закрывает всю историю. Комментарий отображается как обычный текст с переносами строк, без выполнения Markdown/HTML. Если комментария нет, кнопки нет. Это скрывает текст интерфейса до нажатия, но не ограничивает доступ к сохранённым данным.

Заметки связанных тикетов могут содержать Markdown со ссылками на локальные картинки. В подготовленный контекст попадает текст заметок, а не автоматически распознанное содержимое этих изображений.

## Режим работы

Lead и «Разработчик» используют один и тот же набор инструментов ревью: управление разработчиками и отпусками в него не входит. Режим не отключает чтение кода, память, цитаты требований или историю ревью. Переключение режима во время выполняющегося ревью запрещено. Подробности: [Режим работы](work-mode.md).
