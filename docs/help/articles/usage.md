# Использование LLM и логи

Раздел использования LLM показывает запросы, модель, происхождение (чат/ревью), состояние, длительность, доступные входящие/исходящие токены и ошибки. SDK-отчёты — основа счётчика; при неполных отчётах итог может быть частичным.
Вход включает не только текст пользователя: инструкции, доступную историю и результаты инструментов тоже читает модель. Повторные вызовы модели могут повторно учитывать контекст. Бюджет запроса и вместимость окна модели — разные показатели.
Хедер чата относится к выбранному чату; новый чат не должен показывать накопленные токены другого. Модельное окно показывается только если есть данные о нём; не подставляйте выдуманный лимит.
История инструментов: слева пронумерованные вызовы/время, справа параметры и результат. Полный результат включён по умолчанию; переключение краткого помогает смотреть большие ответы. Не считайте размер JSON точным числом токенов без токенизации/SDK-данных.
В результатах ревью тоже есть token usage. Log Review хранится только для последнего запущенного PR-ревью глобально; новое ревью убирает старые инструментальные traces, но не требует уничтожить все результаты/usage. Кнопка скрывается, если лога нет.
При диагностике передавайте reference/ID запроса и текст ошибки без приватных данных. Лог может содержать код/тексты тикетов: не публикуйте его целиком автоматически.

При одновременной работе чата и ревью отчёт показывает отдельные кнопки «Остановить чат» и «Остановить ревью». Они действуют на конкретный активный запрос; если он уже завершился, обновите отчёт. Остановка одного не отменяет другой.
