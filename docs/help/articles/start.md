# Начало работы

## Что делает Orbit
Orbit хранит локальный рабочий список тикетов, заметки, память, сведения о PR и историю ассистента. Azure остаётся источником рабочих задач, статусов, исполнителей, PR и CI. Локальное изменение не всегда является изменением Azure: проверяйте подпись действия.
## Первый запуск
1. Откройте Настройки → GitHub Copilot и подключите аккаунт для чата и ревью.
2. В Настройки → Azure DevOps сохраните PAT и версию REST API. Список необходимых прав находится рядом с PAT.
3. В верхнем хедере откройте «Заказчики и проекты», создайте контекст и настройте «Подключение Azure».
4. В «Репозиторий → Git» задайте имя/ID Git-репозитория. При необходимости включите импорт PR.
5. Выберите заказчика и проект сверху. Импортируйте тикеты/синхронизируйте PR в нужном разделе.
## Разделы
- Обзор: подключения, сводные показатели, активность и использование LLM.
- Тикеты: локальная таблица, просмотр Azure и корзина; поиск, фильтры, импорт, экспорт, массовые операции.
- Разработчики: локальные поручения с группами статусов.
- Pull Requests: активные и завершённые PR, ревью, diff, CI и merge.
- Код репозитория: локальные ветки, дерево, файлы, поиск и Git-работа.
- Подтверждения: предложения памяти и другие действия, требующие явного решения.
- Память: банк общих, клиентских, проектных записей и правил project review.
- Заметки: общие текстовые записи с Markdown и локальными скриншотами; список слева, редактор справа.
- Использование LLM: запросы, токены, ошибки и инструментальные логи.
- Настройки: подключения, ассистент, горячие клавиши, Code Review, язык памяти.
## Общие элементы
Хедер задаёт текущий контекст; меню слева переключает страницы. Кнопка открытия тикета работает по номеру, не требует перехода в таблицу. Правая панель — ассистент текущего контекста. Крестик закрывает попап; закрытие формы не означает сохранение. Кнопки «Сохранить» подтверждают настройки.
Начните с конкретного вопроса: «Как настроить PAT?» или «Почему PR не импортируется?». На общий вопрос о возможностях ассистент отвечает без загрузки всей справки.
