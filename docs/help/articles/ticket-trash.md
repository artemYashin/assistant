# Корзина тикетов

В таблице тикетов кнопка с красной иконкой корзины открывает окно подтверждения с номером тикета. «Отмена» или Escape закрывают окно без удаления; «Удалить в корзину» подтверждает действие.
Удаление тикета в Orbit убирает его из активного локального списка, а не из Azure.
Вкладка корзины показывает сохранённые удалённые тикеты; можно найти и восстановить задачу. Срок хранения — 30 дней, после окончательного удаления локальные данные и кэш очищаются.
Автоматический импорт пропускает корзину, чтобы пользовательское удаление не отменялось следующей синхронизацией. Явное добавление/восстановление может прочитать тикет из Azure и вернуть его.
Пока данные сохранены, ассистент может находить тикеты и описания среди удалённых. Локальный поиск включает сохранённую корзину по умолчанию; можно попросить только активные/только удалённые. Он обязан обозначать результат как удалённый.
Отсутствие тикета после очистки не означает удаление в Azure: при необходимости запросите явный поиск/импорт из Azure.
Связь PR может остаться видна по ID, даже если локального тикета уже нет. Локальные ссылки PR и жизненный цикл самого тикета — разные вещи.

В корзине также доступны фильтр «Azure приоритет» с множественным выбором и кнопка копирования номера справа от ID.

## Компактные даты в таблице

Даты создания, изменения, добавления, синхронизации, удаления и истечения хранения показываются в две строки: дата над временем, как «Локальный дедлайн». Формат — ДД.ММ.ГГ и ЧЧ:ММ в часовом поясе браузера; при наведении доступна полная дата со временем. Это применяется в «Тикетах», «Azure тикетах» и корзине. Отсутствующее или некорректное значение отображается как «—», недоступные для неимпортированного тикета локальные поля — N/A. Формат хранения, сортировка, фильтры и экспорт не меняются.

При просьбе в чате «перенеси выбранные в корзину» ассистент выполняет локальный перенос без повторного подтверждения, включая пакетный инструмент. Список может быть выбран ранее; повторно писать номера не нужно. Это не меняет подтверждение у ручной кнопки удаления в таблице. Импорт и восстановление через ассистента тоже не требуют дополнительного подтверждения; Azure используется только для чтения тикета.
