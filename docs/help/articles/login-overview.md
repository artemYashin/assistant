# Вход, обзор и подключения

## Вход

Orbit автоматически открывает рабочее пространство без пароля — как в новой, так и в существующей установке. Кнопки «Войти» и «Выйти» больше нет. Сессия браузера и CSRF-защита сохраняются; при истечении сессии или ошибке CSRF перезагрузите страницу. Если подключение не удалось, кнопка «Повторить» перезагружает страницу.

При первом запуске обновления миграция удаляет только сохранённый пароль Orbit и старые сессии браузера. Токены Azure/Copilot, ключ шифрования, проекты и рабочие данные сохраняются. Миграция выполняется транзакционно один раз; последующие запуски не сбрасывают новые сессии. Возврат к старой версии может потребовать заново настроить пароль. Перед обновлением можно сохранить резервную копию папки данных при остановленном приложении; восстанавливайте её целиком, вместе с ключом шифрования.

Стандартный Docker Compose публикует приложение только на localhost. Любой, кто имеет доступ к адресу установки, может пользоваться Orbit и подключёнными сервисами; пароль больше не ограничивает этот доступ. Проверки Host, Origin, заголовка интерфейса и CSRF остаются. Старые API входа и создания пароля работают как совместимые адреса создания сессии: присланный пароль игнорируется и не сохраняется. Слишком частое создание сессий требует паузы до 15 минут.

## Обзор

Сводные карточки отражают локально известные показатели выбранного контекста, а не доказанно свежий Azure. Подключения отмечены индикаторами; нажатие открывает соответствующие настройки. «Последняя активность» объясняет недавние операции; использование LLM показывает запросы/расход.
Кнопка подтверждений в хедере ведёт к требующим решения действиям. Кнопка чата раскрывает/сворачивает ассистента, не очищает историю. Сайдбар может сворачиваться; иконки имеют подсказки.

## Приветствие с салютом

В экспериментальной версии `secret-feature` при открытии приложения или перезагрузке вкладки после успешной загрузки данных появляется приветствие с коротким салютом. Оно показывает число тикетов в локальном списке текущего Azure-подключения, без корзины; это не число созданных сегодня или назначенных лично вам тикетов. Дополнительная синхронизация Azure и вызов модели не запускаются. При пустом списке показывается сообщение о чистом старте, при ошибке начальной загрузки приветствие не появляется до успешной загрузки.

«Давай посмотрим» (для пустого списка — «Открыть тикеты») открывает страницу тикетов с сохранёнными фильтрами. Крестик, Escape или «Продолжить с текущей страницы» закрывают приветствие. Между разделами и при фоновом обновлении данных оно не повторяется; новая вкладка или перезагрузка покажут его снова. Салют длится несколько секунд и выключается при системной настройке уменьшения анимаций; текст и кнопки остаются доступны. Сохранённые данные и настройки не меняются, миграция не требуется.
