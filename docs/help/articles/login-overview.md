# Вход, обзор и подключения

## Вход
Первый запуск предлагает создать пароль Orbit (от 12 до 256 символов). Это пароль локального приложения, не PAT Azure и не пароль GitHub. При следующем запуске введите его на странице входа.
Кнопка выхода завершает сессию браузера, не удаляет проекты и не стирает Git-кэш. При сообщении «Войдите в Orbit» заново войдите. Ошибка CSRF/устаревшей сессии может потребовать перезагрузить страницу; не отключайте защиту.
Ограничение попыток входа требует паузы. Не просите пользователя присылать пароль и не предлагайте очистить весь том данных для восстановления доступа.
## Обзор
Сводные карточки отражают локально известные показатели выбранного контекста, а не доказанно свежий Azure. Подключения отмечены индикаторами; нажатие открывает соответствующие настройки. «Последняя активность» объясняет недавние операции; использование LLM показывает запросы/расход.
Кнопка подтверждений в хедере ведёт к требующим решения действиям. Кнопка чата раскрывает/сворачивает ассистента, не очищает историю. Сайдбар может сворачиваться; иконки имеют подсказки.
