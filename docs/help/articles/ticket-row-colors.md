# Цвета строк в Тикетах и Azure тикетах

## Что означает фон строки

В «Azure тикеты» фон показывает локальное состояние тикета в Orbit, а не его рабочий статус в Azure (New, Active, Closed и т. п.). В легенде «Обозначения фона тикетов» есть три состояния:

| Цвет фона                    | Подпись в легенде | Значение                                                                                                                                                     |
| ---------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Обычный белый / слегка серый | Импортирован      | Тикет уже добавлен в локальный список Orbit и не находится в корзине. Лёгкое чередование белых и серых строк помогает читать таблицу и не меняет состояние.  |
| Бледно-красный / розовый     | Не добавлен       | Тикет найден в Azure, но не импортирован в активный локальный список и не находится в локальной корзине. Сам просмотр результатов поиска не импортирует его. |
| Жёлтый / оранжевый           | Удалён            | Тикет был добавлен в Orbit, затем удалён локально и сейчас находится в корзине. Это не удаление задачи на сервере Azure.                                     |

## Почему строка синяя или голубая

Светло-синий / голубой фон обычной кликабельной строки появляется при наведении мыши. Синяя рамка обозначает фокус при навигации клавиатурой. Это не четвёртое состояние импорта. У красных и оранжевых строк наведение усиливает их собственный оттенок.

Выделение галочкой для массовых действий и подсветка найденного тикета после перехода к нему также отдельны от состояния импорта. Не определяйте импорт только по цвету выделения или наведению.

## Что можно сделать

- «Не добавлен»: выберите тикет и используйте «Импортировать выбранное». После успешного импорта он станет локальным.
- «Удалён»: используйте «Восстановить тикет», чтобы вернуть его из локальной корзины.
- «Импортирован»: повторно импортировать этот тикет не нужно.

Локальная корзина имеет срок хранения; подробности — [Корзина тикетов](ticket-trash.md). Оранжевый цвет означает наличие записи в корзине сейчас, а не вечную отметку о любом удалении в прошлом.

## Цвет статуса и типа задачи — другое обозначение

Цветной бейдж внутри столбца статуса или типа задачи не равен фону всей строки. Цвета этих бейджей задаются в «Заказчики и проекты» → «Автоматический импорт». Поэтому красный бейдж статуса сам по себе не означает, что тикет не импортирован. Зелёная кнопка заметок означает наличие заметок, а не статус импорта.
