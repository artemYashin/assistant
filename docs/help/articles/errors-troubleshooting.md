# Ошибки: диагностика

## Сначала определите операцию

Запишите раздел/кнопку, время, точный текст, ID тикета/PR, reference-код и стадию (поиск, чтение, запись, проверка результата). Не передавайте PAT, cookies, Authorization, пароль, полные закрытые логи.
Поиск по справке находит известные сообщения и шаблоны. Совпадение не доказывает конкретную причину. Произвольные ошибки Azure/Git/ОС/модели не могут быть полностью перечислены заранее.

## Типовые группы

- 400 / некорректные параметры: проверьте обязательные поля и ограничения формы; для Azure также URL/проект/репозиторий/API.
- 401/403: подключение, срок токена, scopes и доступ аккаунта. Не просите Full access наугад.
- 404 / не найден: контекст, ID, удаление, права; отсутствие доступа тоже может скрывать ресурс.
- 409: данные/ревизия/подключение изменились; обновите форму и перепроверьте план. Не повторяйте старую запись без проверки.
- 429 / очередь/лимит: дождитесь завершения активной операции; проверьте квоту и лимит запусков. Не создавайте цикл повторов.
- 500: общая внутренняя ошибка, а не диагноз. Нужны reference и серверный журнал с сокрытием секретов.
- 502/503: upstream, некорректный/неполный ответ или недоступный сервис. Проверьте stage и подключение.
- Abort/timeout: отдельные пределы сети, ответа ассистента и Git. Увеличение одного не изменяет другие.

## После записи

Ошибка после PATCH/merge не доказывает, что операция не выполнилась. Сначала проверьте фактическое состояние. Частичный успех показывайте по элементам; не повторяйте успешные действия.

## Специальные случаи

Порог токенов чата: Настройки → AI Assistant → порог входных+выходных токенов. Ревью: Настройки → Code Review и поле бюджета запуска. Максимум инструментов — отдельные лимиты.
Git shallow.lock: проверьте активную работу; не удаляйте lock живого процесса. Недостаточный кэш: лимит CODE_BROWSER_MAX_CACHE_BYTES и доступный диск, не автоматическое удаление данных.
Деталка из кэша: предупреждение означает, что live-загрузка не удалась. Кэш не равен актуальному состоянию.
Микрофон: разрешение браузера, устройство, voice-сервис; model_load/transcribe/audio_too_long различаются.

## Каталог

Ищите точную характерную фразу через search_app_help(scope=all). Статьи errors-* содержат определённые в текущем коде сообщения/шаблоны и источник; {…} — переменная часть. Там могут быть ограничения/подсказки, а не только ошибки. Для действий прочитайте тематическую статью и не запускайте чужую команду из текста ошибки.
