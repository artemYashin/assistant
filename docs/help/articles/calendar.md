# Календарь и напоминания

Откройте «Календарь» в сайдбаре. Календарь и список показывают всё рабочее пространство, не переключаются вместе с заказчиком/проектом и не отправляют события в Azure. Данные сохраняются в локальной базе приложения, в том числе после перезапуска. Удаление проекта не удаляет общие напоминания, но удаляет привязанные к этому проекту записи вместе с остальными его данными. Переименование заказчика/проекта обновляет привязки напоминаний.

## Создание и завершение

«Создать», число дня или свободный час в сетке открывает форму. Укажите название и необязательное описание. Отдельного селектора типа больше нет:
- Без начала и окончания — общее напоминание без срока.
- Только начало — напоминание на конкретное время, без длительности.
- Начало и окончание — событие с длительностью. Окончание не может быть раньше начала; без начала оно недоступно.

До начала запись имеет пометку «Предстоит», внутри интервала — «Идёт сейчас», после наступления времени напоминания или окончания события — «Просрочено». Это не завершение: поле завершения меняется только вручную. Напоминание без даты постоянно активно до завершения/удаления.

Вверху формы выберите «Уровень напоминания»: «Общий», «Заказчик», «Проект». Для последних двух выберите заказчика, а для проектного — ещё проект. Новая форма подставляет текущий контекст из хедера, но его можно поменять. Привязка не ограничивает видимость списка и доставку уведомлений. Старые записи при обновлении получают общий уровень, их содержимое и отметка завершения сохраняются.

Разработчики необязательны: можно выбрать несколько локальных разработчиков из общего списка, заказчиков и проектов. У каждого показана аватарка с инициалами. Это участники для ориентира; сообщения им не отправляются. Создание, сохранение изменений, завершение и удаление требуют confirmation-попапа. Завершённые записи остаются в истории и перестают напоминать о себе. Чтобы отменить случайное завершение, выберите фильтр «Завершено» и нажмите «Вернуть в незавершённые». После подтверждения запись снова активна, общий таймер уведомлений не сбрасывается. Уже наступившее напоминание войдёт в следующую общую подборку с учётом интервала и расписания; будущее дождётся начала. Удаление необратимо. В деталке существующего напоминания также доступны «Завершить», «Вернуть в незавершённые» для завершённого и «Удалить» — каждое действие с подтверждением. Эти действия не сохраняют несохранённые правки формы. После успешного действия деталка закрывается; завершённое событие остаётся в календаре зелёным.

## Календарь и список

Во вкладке «Календарь» переключайте «Месяц / Неделя / День». По умолчанию открыта неделя. В календаре остаются и активные, и завершённые события: завершённые выделены зелёным, незавершённые — оранжевым, просроченные — красным. Цветовая легенда показана над сеткой. «Ещё…» открывает список за день со всеми состояниями. Напоминания без даты по-прежнему доступны в списке. В неделе и дне слева шкала часов, события расположены по времени начала и длительности; одновременные события показаны рядом. Сетка прокручивается внутри своего блока. При открытии дневного или недельного вида, переключении периода и смене часового пояса она автоматически показывает текущее время примерно в центре видимой области. Дальше можно прокручивать вручную: обновление часов не сбрасывает положение. Нажатие свободного часа создаёт запись с этим началом. Для напоминания без длительности используется маленькая кликабельная область, это не добавляет ему длительность в данных. Многодневное событие разделяется по дням.

В видах «Неделя» и «День» перетащите событие на другое время или день; длительность сохраняется. Потяните нижний край последнего дня события, чтобы изменить окончание (минимум 15 минут). Напоминание без длительности при растягивании становится событием. Шаг движения — 15 минут; возле верхнего и нижнего края сетка автоматически прокручивается. После отпускания откроется подтверждение с прежним и новым временем. Только «Подтвердить» сохраняет изменение; «Отмена» или Escape оставляют прежние данные. Escape во время самого перетаскивания отменяет жест. При ошибке сохранения окно остаётся открытым для повторной попытки. Обычный клик по событию по-прежнему открывает форму точного ввода дат.

Месячная сетка компактная, без лишней шестой недели, если месяц помещается в пять. Стрелки переключают выбранный период, «Сегодня» возвращает текущий; поле даты позволяет быстро перейти к нужному дню. Поля начала, окончания и диапазона открывают стилизованный календарик: стрелки переключают месяцы, сегодняшний и выбранный дни выделены, часы и минуты вводятся отдельно. «Сегодня» выбирает текущую дату в настроенном часовом поясе. Кнопка «Выбрать» применяет дату и время; «Отмена», Escape или клик за пределами календарика закрывают его без изменений. Стрелки клавиатуры перемещают выбор по дням. Для окончания недоступны дни раньше начала; время окончания также не может быть раньше начала. «Сбросить» возле поля очищает дату. Сохранение самого напоминания по-прежнему требует отдельного подтверждения. Нажатие события открывает его форму, «Ещё…» в месяце переводит к списку за этот день. Напоминания без даты находятся во вкладке «Напоминания».

В списке доступны поиск по названию, состояние, отдельные фильтры «Заказчик» и «Проект» (включая «Без заказчика» / «Без проекта») и диапазон «С»/«По». Выбранные нестандартные значения селекторов подсвечиваются зелёным. Проекты с одинаковым названием различаются заказчиком. Смена контекста хедера не меняет эти фильтры. Границы включены: событие 08:00–10:00 входит в диапазон 09:00–11:00. Учитывается любое пересечение, а не только начало. Напоминание только с началом попадает в диапазон по своему моменту времени; отсутствие окончания не растягивает его на последующие дни. Старые записи без окончания теперь также отображаются как напоминания без длительности, даты и ручное завершение сохраняются. Напоминания без даты не входят в фильтр по времени. По умолчанию состояние — «Все»: завершённое напоминание остаётся в списке с пометкой «Завершено». «Сбросить» возвращает состояние «Все» и очищает остальные фильтры. Чтобы оставить только незавершённые записи, выберите «Все активные»; для просмотра истории — «Завершено».

## Часовой пояс

В настройках «Календарь» заголовок отделён от содержимого линией и отступом, как в остальных разделах.

«Настройки» → «Календарь» → «Часовой пояс»: IANA-название, например Asia/Bishkek или Europe/Berlin. Этот же пояс применяется к расписанию автообновлений, которое остаётся в Azure DevOps. Существующая настройка пояса сохраняется при обновлении приложения.

В базе хранятся абсолютные моменты UTC. Изменение пояса меняет отображение, но не переносит уже созданное событие. Ввод дат и фильтров использует выбранный пояс, даже если у браузера другой. Несуществующее время при весеннем переводе часов отклоняется; при осеннем повторении часа используется первое вхождение.

## Центр уведомлений и алерты

Колокольчик в хедере объединяет ожидающие подтверждения и все активные напоминания, включая будущие. Рядом показан бейдж с их суммарным количеством; при нуле он скрыт. Закрытие экранного алерта не уменьшает счётчик: напоминание остаётся активным. Нажатие напоминания открывает его в календаре. Закрытие алерта или окна уведомлений не завершает и не удаляет запись.

Когда наступает начало события/напоминания, либо создано общее напоминание, приложение показывает алерт поверх окон с кнопкой закрытия. Таймера скрытия нет: алерт остаётся на экране до нажатия крестика. Переход к напоминанию тоже не закрывает алерт. Следующие алерты повторяются по настроенному интервалу и расписанию, пока запись активна. Проверка выполняется примерно каждые 15 секунд; браузер может замедлять фоновые вкладки. Новые напоминания добавляются к уже видимым, а повторные с тем же ID не дублируются и не вытесняют другие. Длинный список прокручивается. Завершённые или удалённые напоминания убираются из алерта при следующей проверке. Крестик справа от отдельного напоминания скрывает только его, оставляя остальные на экране. Общий крестик вверху закрывает весь текущий алерт; после закрытия последнего напоминания блок исчезает. Сами записи остаются в центре уведомлений и могут снова напомнить о себе по расписанию. После сна/перезапуска активные пропущенные события остаются в списке; уведомление показывается при следующей разрешённой проверке после истечения общего интервала.

«Настройки» → «Календарь» → «Присылать уведомления из браузера» включает системные уведомления. «Разрешить уведомления» запрашивает разрешение браузера; при отказе измените разрешение в настройках сайта. Нужен поддерживаемый браузер и безопасный контекст HTTPS или localhost. Встроенные алерты работают без системного разрешения.

При включённом чекбоксе можно менять интервал (1–10080 минут), режим, дни недели и часы уведомлений. При выключенном настройки видны, но недоступны для изменения; встроенные алерты продолжают использовать сохранённое расписание. По умолчанию — раз в 60 минут в любое время. Ночной интервал относится к дню начала; одинаковые часы означают весь день; пустой список дней выключает расписание. В хедере напоминания остаются видимыми вне расписания.

Orbit должен быть открыт хотя бы в одной вкладке, а сервер — доступен. Здесь нет push-доставки при полностью закрытом браузере. Разрешение браузера относится к текущему устройству; расписание хранится в приложении. Сервер запоминает выдачу уведомлений, чтобы несколько вкладок не повторяли их одновременно; при нескольких браузерах алерт получает первый выполнивший проверку. Это не гарантированная служба доставки: сбой сети, закрытие вкладки или ограничения ОС могут задержать/потерять конкретный алерт; сама запись остаётся в центре уведомлений.


## Дедлайны тикетов

«Локальный дедлайн» в таблице или деталке импортированного тикета создаёт связанное напоминание «Дедлайн #…». Это отдельная связь с тикетом, а не событие Azure. В настройках «Календарь» поле «Предупреждать о дедлайне тикета за (часы)» задаёт начало предупреждения: по умолчанию 24 часа, можно указать 5 или 48; 0 означает в момент дедлайна. Настройка применяется и к существующим дедлайнам, не сбрасывая завершение.

В календаре запись располагается в момент начала предупреждения; фактический дедлайн показан в её деталке. До предупреждения — «Предстоит», между предупреждением и дедлайном — «Идёт сейчас», после дедлайна — «Просрочено». Автоматического завершения нет. В фильтре дат связанное напоминание пересекает любой интервал после начала предупреждения. В часовой сетке у записи компактная область вместо бесконечной полосы.

«Завершить» прекращает уведомления, сохраняя дедлайн тикета. «Вернуть в незавершённые» возобновляет их. Перенос дедлайна в карточке тикета обновляет ту же запись и снова делает её активной. Повторное сохранение того же срока и правки других полей не сбрасывают завершение. Перетаскивание/растягивание для этой записи выключено: срок меняется через «Открыть тикет». Удаление связанного напоминания с подтверждением очищает также локальный дедлайн; очистка поля дедлайна удаляет напоминание.

Дедлайны общие для тикета в одном подключении Azure, не дублируются для локальных проектов. В корзине поле сохраняется, но напоминание не показывается и не уведомляет; восстановление возвращает прежнее состояние. Окончательная очистка локальных данных тикета удаляет связанное напоминание.

Каждое экранное уведомление оформлено отдельной карточкой. Крестик скрывает только этот алерт, а галочка «Завершить» открывает подтверждение завершения. После завершения запись исчезает из активных уведомлений, но остаётся в календаре. Закрытие крестиком не завершает напоминание и не запрещает следующие уведомления по расписанию.

## Напоминания через чат

Попросите ассистента, например: «Напомни через десять минут проверить сборку», «Напомни сегодня вечером» или «Создай событие завтра с 10 до 11». Ассистент получает текущее время и часовой пояс календаря, затем открывает заполненную форму. Проверьте дату, время, уровень и разработчиков: создание происходит только после вашего подтверждения в форме. Без начала и конца получится напоминание без срока. Неоднозначное время можно уточнить в разговоре или исправить в форме. Инструмент не создаёт запись молча и не сообщает об успешном сохранении до вашего действия.


## Ежедневные напоминания

В форме задайте начало и включите «Повторять каждый день». Дата начала — первый день серии, время — ежедневное время срабатывания. Окончание необязательно; если задано, длительность ежедневного события не должна превышать сутки. Повтор не зависит от уровня «Общий / Заказчик / Проект». Для связанных дедлайнов тикетов он недоступен.

В базе сохраняется одна запись. Месячный, недельный и дневной календарь показывают её виртуальные повторения с даты начала, а вкладка «Напоминания» — одну строку «Ежедневно». Фильтр дат учитывает попадание конкретных повторений в выбранный диапазон. Нажатие любого повторения открывает всю серию; изменение времени/даты относится ко всей серии. Перетаскивание и растягивание серии отключены, используйте форму.

Ежедневная серия начинает уведомлять после выбранного времени и повторяет уведомления по интервалу и расписанию из настроек календаря. Крестик скрывает текущий алерт, но не останавливает повторные уведомления. Если Orbit открыт позже, напоминание за текущий день войдёт в ближайшую общую подборку с учётом интервала и расписания; пропущенные дни не создают накопленную очередь.

Доступны два отдельных действия с подтверждением: «Завершить сегодня» и «Завершить всю серию». Первое прекращает уведомления до следующего дня, сохраняет отметку за сегодняшнюю дату и выделяет это повторение зелёным. Завтра та же запись снова уведомляет после своего времени. Второе завершает всю серию. «Возобновить сегодня» отменяет случайное завершение текущей итерации и возобновляет уведомления. «Вернуть в незавершённые» возвращает серию, сохраняя отметки отдельных дней. В экранном блоке «Обратите внимание» для ежедневной серии есть только «Завершить сегодня» с подтверждением. Завершить всю серию из этого блока нельзя: откройте календарь и используйте отдельное действие «Завершить всю серию». Для обычного напоминания в уведомлении остаётся «Завершить» с подтверждением. Дата «сегодня» определяется часовым поясом серии, даже если в календаре открыт другой день. В базе по-прежнему одна запись с отметками завершённых дат, без ежедневного создания новых сущностей.

Часовой пояс серии запоминается при её создании. Ежедневное время остаётся местным временем этого пояса при смене летнего/зимнего времени. Несуществующий час при весеннем переходе пропускается в этот день; при повторяющемся часе выбирается первое вхождение. Изменение общей настройки часового пояса меняет отображение, но не переносит время уже созданной серии.

Пересекающиеся напоминания разрешены, в том числе несколько ежедневных серий в одно время. В дне и неделе они располагаются рядом; ограничений уникальности времени нет. Ассистент также умеет подготовить ежедневную серию через `prepare_calendar_reminder` с `repeatDaily: true`; сохранение требует вашего подтверждения.

## Читаемость временной сетки

В режимах дня и недели час занимает 120 пикселей, полчаса — 60. Область календаря прокручивается; подписи часов, линия текущего времени, перенос и растягивание используют один масштаб. Название события показано первым, до двух строк; полное название доступно при наведении и в деталях. У напоминаний о тикетах сверху видны номер и название, ниже — сам дедлайн, а положение в сетке по-прежнему соответствует началу предупреждения.

Разработчики напоминания о локальном дедлайне берутся напрямую из локальных поручений соответствующего тикета (с учётом его Azure-подключения). Изменение или очистка поручений отражается при следующем чтении календаря, в том числе для ранее созданных напоминаний; завершение напоминания при этом не сбрасывается. Отдельно редактировать этот список в напоминании нельзя — используйте карточку тикета. Это локальные разработчики, не исполнитель Azure.

## Общий цикл повторных уведомлений

«Общий интервал, минуты» в настройках календаря задаёт один таймер для всех напоминаний, ежедневных серий и дедлайнов тикетов во всех заказчиках и проектах. По истечении интервала при ближайшей разрешённой расписанием проверке приложение собирает весь актуальный набор: начавшиеся, идущие сейчас, просроченные и общие напоминания без даты. Завершённые записи, завершённые сегодняшние итерации серий и будущие события в подборку не входят. Ограничения в 20 напоминаний на одну подборку нет.

Интервал отсчитывается от последней непустой подборки, а не от времени отдельного события. Например, после уведомления в 10:00 при интервале 60 минут начавшееся в 10:20 событие попадёт в общую подборку в 11:00 вместе с остальными актуальными. Создание, редактирование, возобновление и закрытие алерта не сбрасывают общий таймер. Если активных напоминаний нет, пустое уведомление не показывается и отсчёт не сдвигается.

Метка последней подборки сохраняется в базе: обновление страницы, смена проекта и перезапуск сервера не обнуляют интервал. Несколько вкладок не забирают одну подборку повторно. Вне разрешённого расписания уведомлений нет; после возвращения в разрешённое время отправляется один актуальный набор, без очереди пропущенных интервалов. Проверка выполняется открытым приложением примерно раз в 15 секунд. Без открытого Orbit фоновой системной отправки нет. Первый набор при отсутствии истории отправок приходит при ближайшей разрешённой проверке.
