# Календарь и напоминания

Откройте «Календарь» в сайдбаре. Календарь общий для рабочего пространства, не переключается вместе с заказчиком/проектом и не отправляет события в Azure. Данные сохраняются в локальной базе приложения, в том числе после перезапуска. Удаление проекта не удаляет общие напоминания.

## Создание и завершение

«Создать» или число дня в месяце открывает форму. Укажите название, необязательное описание и тип:
- «Напоминание на дату и время» — один момент. После наступления времени считается просроченным до ручного завершения.
- «Событие с длительностью» — начало и необязательное окончание. До начала «Предстоит», затем «Идёт сейчас», после окончания «Просрочено». Без окончания событие продолжает идти до завершения пользователем.
- «Общее напоминание без срока» — без даты, постоянно доступно во вкладке «Напоминания» и уведомлениях до завершения или удаления.

Разработчики необязательны: можно выбрать несколько локальных разработчиков из общего списка, заказчиков и проектов. Это участники для ориентира; сообщения им не отправляются. Создание, сохранение изменений, завершение и удаление требуют confirmation-попапа. Завершённые записи остаются в истории и перестают напоминать о себе. Удаление необратимо.

## Календарь и список

Вкладка «Календарь» показывает месяц; стрелки переключают месяцы, «Сегодня» возвращает текущий. События с длительностью видны во всех затронутых днях. Нажатие события открывает его форму, «Ещё…» переводит к списку за этот день. Общие напоминания без даты находятся во вкладке «Напоминания».

В списке доступны поиск по названию, состояние и диапазон «С»/«По». Границы включены: событие 08:00–10:00 входит в диапазон 09:00–11:00. Учитывается любое пересечение, а не только начало. Событие без окончания пересекается со всеми последующими диапазонами. Напоминания без даты не входят в фильтр по времени. «Сбросить» возвращает все активные записи. Для истории выберите «Завершено» или «Все, включая завершённые».

## Часовой пояс

«Настройки» → «Календарь» → «Часовой пояс»: IANA-название, например Asia/Bishkek или Europe/Berlin. Этот же пояс применяется к расписанию автообновлений, которое остаётся в Azure DevOps. Существующая настройка пояса сохраняется при обновлении приложения.

В базе хранятся абсолютные моменты UTC. Изменение пояса меняет отображение, но не переносит уже созданное событие. Ввод дат и фильтров использует выбранный пояс, даже если у браузера другой. Несуществующее время при весеннем переводе часов отклоняется; при осеннем повторении часа используется первое вхождение.

## Центр уведомлений и алерты

Колокольчик в хедере объединяет ожидающие подтверждения и все активные напоминания, включая будущие. Нажатие напоминания открывает его в календаре. Закрытие алерта или окна уведомлений не завершает и не удаляет запись.

Когда наступает начало события/напоминания, либо создано общее напоминание, приложение показывает алерт поверх окон, с кнопкой закрытия и полосой оставшихся 10 секунд. Следующие алерты повторяются по настроенному интервалу и расписанию, пока запись активна. Проверка выполняется примерно каждые 15 секунд; браузер может замедлять фоновые вкладки. Несколько одновременно наступивших записей объединяются. После сна/перезапуска активные пропущенные события остаются в списке; уведомление показывается при следующей разрешённой проверке.

«Настройки» → «Календарь» → «Присылать уведомления из браузера» включает системные уведомления. «Разрешить уведомления» запрашивает разрешение браузера; при отказе измените разрешение в настройках сайта. Нужен поддерживаемый браузер и безопасный контекст HTTPS или localhost. Встроенные алерты работают без системного разрешения.

При включённом чекбоксе можно менять интервал (1–10080 минут), режим, дни недели и часы уведомлений. При выключенном настройки видны, но недоступны для изменения; встроенные алерты продолжают использовать сохранённое расписание. По умолчанию — раз в 60 минут в любое время. Ночной интервал относится к дню начала; одинаковые часы означают весь день; пустой список дней выключает расписание. В хедере напоминания остаются видимыми вне расписания.

Orbit должен быть открыт хотя бы в одной вкладке, а сервер — доступен. Здесь нет push-доставки при полностью закрытом браузере. Разрешение браузера относится к текущему устройству; расписание хранится в приложении. Сервер запоминает выдачу уведомлений, чтобы несколько вкладок не повторяли их одновременно; при нескольких браузерах алерт получает первый выполнивший проверку. Это не гарантированная служба доставки: сбой сети, закрытие вкладки или ограничения ОС могут задержать/потерять конкретный алерт; сама запись остаётся в центре уведомлений.
