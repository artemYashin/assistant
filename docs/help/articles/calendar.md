# Календарь и напоминания

Откройте «Календарь» в сайдбаре. Календарь и список показывают всё рабочее пространство, не переключаются вместе с заказчиком/проектом и не отправляют события в Azure. Данные сохраняются в локальной базе приложения, в том числе после перезапуска. Удаление проекта не удаляет общие напоминания, но удаляет привязанные к этому проекту записи вместе с остальными его данными. Переименование заказчика/проекта обновляет привязки напоминаний.

## Создание и завершение

«Создать», число дня или свободный час в сетке открывает форму. Укажите название и необязательное описание. Отдельного селектора типа больше нет:
- Без начала и окончания — общее напоминание без срока.
- Только начало — напоминание на конкретное время, без длительности.
- Начало и окончание — событие с длительностью. Окончание не может быть раньше начала; без начала оно недоступно.

До начала запись имеет пометку «Предстоит», внутри интервала — «Идёт сейчас», после наступления времени напоминания или окончания события — «Просрочено». Это не завершение: поле завершения меняется только вручную. Напоминание без даты постоянно активно до завершения/удаления.

Вверху формы выберите «Уровень напоминания»: «Общий», «Заказчик», «Проект». Для последних двух выберите заказчика, а для проектного — ещё проект. Новая форма подставляет текущий контекст из хедера, но его можно поменять. Привязка не ограничивает видимость списка и доставку уведомлений. Старые записи при обновлении получают общий уровень, их содержимое и отметка завершения сохраняются.

Разработчики необязательны: можно выбрать несколько локальных разработчиков из общего списка, заказчиков и проектов. У каждого показана аватарка с инициалами. Это участники для ориентира; сообщения им не отправляются. Создание, сохранение изменений, завершение и удаление требуют confirmation-попапа. Завершённые записи остаются в истории и перестают напоминать о себе. Чтобы отменить случайное завершение, выберите фильтр «Завершено» и нажмите «Вернуть в незавершённые». После подтверждения запись снова активна, отметка последнего уведомления сбрасывается. Для уже наступившего напоминания уведомления возобновятся при ближайшей разрешённой проверке; будущее дождётся начала. Удаление необратимо.

## Календарь и список

Во вкладке «Календарь» переключайте «Месяц / Неделя / День». По умолчанию открыта неделя. В неделе и дне слева шкала часов, события расположены по времени начала и длительности; одновременные события показаны рядом. Сетка прокручивается внутри своего блока. При открытии дневного или недельного вида, переключении периода и смене часового пояса она автоматически показывает текущее время примерно в центре видимой области. Дальше можно прокручивать вручную: обновление часов не сбрасывает положение. Нажатие свободного часа создаёт запись с этим началом. Для напоминания без длительности используется маленькая кликабельная область, это не добавляет ему длительность в данных. Многодневное событие разделяется по дням.

В видах «Неделя» и «День» перетащите событие на другое время или день; длительность сохраняется. Потяните нижний край последнего дня события, чтобы изменить окончание (минимум 15 минут). Напоминание без длительности при растягивании становится событием. Шаг движения — 15 минут; возле верхнего и нижнего края сетка автоматически прокручивается. После отпускания откроется подтверждение с прежним и новым временем. Только «Подтвердить» сохраняет изменение; «Отмена» или Escape оставляют прежние данные. Escape во время самого перетаскивания отменяет жест. При ошибке сохранения окно остаётся открытым для повторной попытки. Обычный клик по событию по-прежнему открывает форму точного ввода дат.

Месячная сетка компактная, без лишней шестой недели, если месяц помещается в пять. Стрелки переключают выбранный период, «Сегодня» возвращает текущий; поле даты позволяет быстро перейти к нужному дню. Поля начала, окончания и диапазона открывают стилизованный календарик: стрелки переключают месяцы, сегодняшний и выбранный дни выделены, часы и минуты вводятся отдельно. «Сегодня» выбирает текущую дату в настроенном часовом поясе. Кнопка «Выбрать» применяет дату и время; «Отмена», Escape или клик за пределами календарика закрывают его без изменений. Стрелки клавиатуры перемещают выбор по дням. Для окончания недоступны дни раньше начала; время окончания также не может быть раньше начала. «Сбросить» возле поля очищает дату. Сохранение самого напоминания по-прежнему требует отдельного подтверждения. Нажатие события открывает его форму, «Ещё…» в месяце переводит к списку за этот день. Напоминания без даты находятся во вкладке «Напоминания».

В списке доступны поиск по названию, состояние, отдельные фильтры «Заказчик» и «Проект» (включая «Без заказчика» / «Без проекта») и диапазон «С»/«По». Выбранные нестандартные значения селекторов подсвечиваются зелёным. Проекты с одинаковым названием различаются заказчиком. Смена контекста хедера не меняет эти фильтры. Границы включены: событие 08:00–10:00 входит в диапазон 09:00–11:00. Учитывается любое пересечение, а не только начало. Напоминание только с началом попадает в диапазон по своему моменту времени; отсутствие окончания не растягивает его на последующие дни. Старые записи без окончания теперь также отображаются как напоминания без длительности, даты и ручное завершение сохраняются. Напоминания без даты не входят в фильтр по времени. По умолчанию состояние — «Все»: завершённое напоминание остаётся в списке с пометкой «Завершено». «Сбросить» возвращает состояние «Все» и очищает остальные фильтры. Чтобы оставить только незавершённые записи, выберите «Все активные»; для просмотра истории — «Завершено».

## Часовой пояс

«Настройки» → «Календарь» → «Часовой пояс»: IANA-название, например Asia/Bishkek или Europe/Berlin. Этот же пояс применяется к расписанию автообновлений, которое остаётся в Azure DevOps. Существующая настройка пояса сохраняется при обновлении приложения.

В базе хранятся абсолютные моменты UTC. Изменение пояса меняет отображение, но не переносит уже созданное событие. Ввод дат и фильтров использует выбранный пояс, даже если у браузера другой. Несуществующее время при весеннем переводе часов отклоняется; при осеннем повторении часа используется первое вхождение.

## Центр уведомлений и алерты

Колокольчик в хедере объединяет ожидающие подтверждения и все активные напоминания, включая будущие. Рядом показан бейдж с их суммарным количеством; при нуле он скрыт. Закрытие экранного алерта не уменьшает счётчик: напоминание остаётся активным. Нажатие напоминания открывает его в календаре. Закрытие алерта или окна уведомлений не завершает и не удаляет запись.

Когда наступает начало события/напоминания, либо создано общее напоминание, приложение показывает алерт поверх окон с кнопкой закрытия. Таймера скрытия нет: алерт остаётся на экране до нажатия крестика. Переход к напоминанию тоже не закрывает алерт. Следующие алерты повторяются по настроенному интервалу и расписанию, пока запись активна. Проверка выполняется примерно каждые 15 секунд; браузер может замедлять фоновые вкладки. Новые напоминания добавляются к уже видимым, а повторные с тем же ID не дублируются и не вытесняют другие. Длинный список прокручивается. Завершённые или удалённые напоминания убираются из алерта при следующей проверке. Крестик справа от отдельного напоминания скрывает только его, оставляя остальные на экране. Общий крестик вверху закрывает весь текущий алерт; после закрытия последнего напоминания блок исчезает. Сами записи остаются в центре уведомлений и могут снова напомнить о себе по расписанию. После сна/перезапуска активные пропущенные события остаются в списке; уведомление показывается при следующей разрешённой проверке.

«Настройки» → «Календарь» → «Присылать уведомления из браузера» включает системные уведомления. «Разрешить уведомления» запрашивает разрешение браузера; при отказе измените разрешение в настройках сайта. Нужен поддерживаемый браузер и безопасный контекст HTTPS или localhost. Встроенные алерты работают без системного разрешения.

При включённом чекбоксе можно менять интервал (1–10080 минут), режим, дни недели и часы уведомлений. При выключенном настройки видны, но недоступны для изменения; встроенные алерты продолжают использовать сохранённое расписание. По умолчанию — раз в 60 минут в любое время. Ночной интервал относится к дню начала; одинаковые часы означают весь день; пустой список дней выключает расписание. В хедере напоминания остаются видимыми вне расписания.

Orbit должен быть открыт хотя бы в одной вкладке, а сервер — доступен. Здесь нет push-доставки при полностью закрытом браузере. Разрешение браузера относится к текущему устройству; расписание хранится в приложении. Сервер запоминает выдачу уведомлений, чтобы несколько вкладок не повторяли их одновременно; при нескольких браузерах алерт получает первый выполнивший проверку. Это не гарантированная служба доставки: сбой сети, закрытие вкладки или ограничения ОС могут задержать/потерять конкретный алерт; сама запись остаётся в центре уведомлений.
