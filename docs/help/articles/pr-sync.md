# PR: импорт и фильтры

## Настройки
Заказчики и проекты → Подключение Azure: корректные URL и Azure-проект.
Репозиторий → Git: точное имя или ID репозитория.
Репозиторий → Pull request: включите «Синхронизировать PR». «Все активные PR» снимает фильтрацию по ревьюерам и отключает списки выбора.
Если «Все активные PR» выключено, задайте людей в Required и/или Optional. Совпадения работают как ИЛИ: любой выбранный человек с соответствующей ролью допускает PR. Пустые фильтры не означают «все»; настройте список. Автор PR и его ревьюер — разные поля.
## Кнопка синхронизации
«Синхронизировать PR» обозначена иконкой обновления, как синхронизация тикетов.
Получает список активных PR с пагинацией, фильтрует по настройкам, затем для каждого импортируемого PR получает полную деталку, чтобы разбирать полные title/description. Дополнительно читает явные связи и проверки.
Полное сканирование должно завершиться до замены активного списка. Неудачная страница не должна скрывать все ранее известные PR. Ошибки политик/связей отмечаются отдельно.
После сохранения Orbit пытается импортировать недостающие связанные тикеты. Не импортируются локально исключённые связи и задачи из корзины. Это дополнение к PR-импорту, не полная синхронизация всех тикетов.
## Что показывается
Автор, название, дата, source/target, состояние ревью, конфликты, CI и готовность локальной ветки. Статусы — сохранённые результаты проверок, не непрерывный live-запрос.
Изменение версии source/target может сделать старое ревью устаревшим. Фильтры текущей страницы и ограничения источника не одно и то же.
При 400 проверьте endpoint ошибки, URL организации, Azure-проект и репозиторий; при 401/403 — PAT и права. Не заменяйте пробелы проекта вручную в разных местах случайным образом.

## Фильтры страницы
Компактный синий блок объединяет кнопку «Сбросить фильтры» слева, тип PR, готовность ревью и сортировку в одной строке на широком экране. Счётчик «Показано … из …» находится под блоком. Значения, отличающиеся от «Все PR», «Все состояния» и «Созданы: сначала новые», подсвечиваются зелёным. Выбор сохраняется в этом браузере между обновлениями страницы отдельно для каждого заказчика, общий для его проектов. «Сбросить фильтры» возвращает и сохраняет значения по умолчанию. При открытии конкретного PR по ссылке фильтры временно не применяются, сохранённый выбор остаётся. Эти фильтры меняют только показ локального списка, не настройки импорта из Azure.

## Обновить один активный PR
Компактная кнопка «Обновить» находится справа сверху карточки рядом с контекстом PR и версией изменений. После подтверждения Orbit запрашивает полную деталку, актуальные Azure-связи и проверки только этого PR. Остальные PR не пересинхронизируются. Ручные локальные привязки тикетов и отметки «Не учитывать» сохраняются. Обновляются связи из описания, названия и Azure; локальные исключения продолжают действовать, в том числе если связь вновь появилась в Azure. Сброс локальных связей остаётся только у переимпорта завершённых PR. Изменения в Azure не вносятся.
Если деталка или связи не загрузились, прежние данные и локальные связи сохраняются. Ошибка загрузки проверок отмечается отдельно и не мешает обновить деталку. Если PR уже завершён/закрыт или подключение изменилось, обновление отклоняется: синхронизируйте список. Изменение source/target делает прежнее ревью устаревшим по обычным правилам.
