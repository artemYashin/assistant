# Вопросы ревьюера

Карточка «Вопросы к PR» появляется, когда ревьюеру нужны уточнения. Показывает PR, контекст, вопрос и причину.
Заполните все ответы; если данных нет, можно написать «Не знаю». Кнопка «Отправить все ответы и повторить ревью» отправляет набор целиком. Можно проигнорировать вопросы и завершить ревью, осознавая, что неопределённость останется.
Закрытый набор помечается «Ответы отправлены», «Неактуально» или «Вопросы проигнорированы» и не принимает новый ответ как будто это свежий вопрос.
Изменение версии PR может сделать набор неактуальным. Продолжение относится к общему контексту/бюджету ревью, а не обнуляет токены каждого файла. Частота вопросов настраивается при запуске; общий бюджет/инструменты — в Code Review.
Ссылка «Перейти к PR» открывает карточку соответствующего PR. Вопросы ревьюера не являются предложениями памяти и не должны автоматически сохраняться в память.

## Удалить из входящих

На странице Pull Requests → «Входящие» у каждого набора есть кнопка-иконка корзины «Удалить из входящих вопросы к PR #…». Она доступна и для ожидающих ответа, и для закрытых/неактуальных наборов. Подтверждение «Удалить из входящих» убирает карточку из списка и счётчиков; отмена ничего не меняет.

Если этот набор ещё ожидает ответа и ревью находится в состоянии ожидания, оно завершается без ответов, с отметкой о сохранившихся неопределённостях. Уже запущенное, поставленное в очередь или завершённое ревью не останавливается и не перезапускается. Удаление относится только к выбранному набору, не ко всем вопросам этого PR. Новые вопросы могут появиться отдельной карточкой.

Это локальное удаление из списка: вопросы, отправленные ответы и результат ревью сохраняются для истории и продолжения анализа. PR, тикеты и данные Azure не удаляются. Карточка не возвращается после перезагрузки; кнопки восстановления нет. При ошибке операции запись остаётся во входящих — можно повторить попытку.

При обновлении существующей установки добавляется отдельная таблица отметок удаления; прежние наборы остаются видимыми, их ID, ответы и связи с ревью сохраняются. Повторный запуск приложения не сбрасывает отметки.
