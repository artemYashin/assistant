# Вопросы ревьюера

Карточка «Вопросы к PR» появляется, когда ревьюеру нужны уточнения. Показывает PR, контекст, вопрос и причину.
Заполните все ответы; если данных нет, можно написать «Не знаю». Кнопка «Отправить все ответы и повторить ревью» отправляет набор целиком. Можно проигнорировать вопросы и завершить ревью, осознавая, что неопределённость останется.
Закрытый набор помечается «Ответы отправлены», «Неактуально» или «Вопросы проигнорированы» и не принимает новый ответ как будто это свежий вопрос.
Изменение версии PR может сделать набор неактуальным. Продолжение относится к общему контексту/бюджету ревью, а не обнуляет токены каждого файла. Частота вопросов настраивается при запуске; общий бюджет/инструменты — в Code Review.
Ссылка «Перейти к PR» открывает карточку соответствующего PR. Вопросы ревьюера не являются предложениями памяти и не должны автоматически сохраняться в память.
