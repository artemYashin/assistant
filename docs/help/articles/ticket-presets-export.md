# Фильтры и экспорт тикетов

## Наборы фильтров
Раскройте блок наборов, задайте условия поиска/сортировки и название, нажмите «Сохранить набор». Повторное имя предлагает подтверждение перезаписи. Нажатие набора применяет сохранённые условия; индикатор изменения показывает отклонение от сохранённого набора.
Наборы можно переупорядочить и удалить. Удаление набора не удаляет тикеты. Кнопка сброса снимает выбранный набор, условия и поиск, а не оставляет его выделенным.
## Колонки
Меню столбцов меняет видимость. Разделители позволяют изменять ширину. Настройки таблицы/экспорта — разные наборы: скрытая колонка не обязана исчезнуть из формы экспорта.
## Экспорт
Кнопка «Экспорт» открывает общее окно CSV/Excel. Формат выбирается сверху. Слева показаны только отмеченные в таблице тикеты; без выбора окно открывается с пустым списком, а скачивание недоступно. Форма фиксирует снимок выбранных тикетов, не меняя выбор таблицы.
Список прокручивается. Крестик убирает тикет только из экспорта. «Добавить тикет» открывает поиск по номеру или названию среди локальных задач текущего Azure-подключения, включая корзину; Azure не запрашивается. Выберите результат, чтобы добавить его; повторно добавить тот же ID нельзя. Крестик у поиска отменяет добавление. Показаны первые 20 совпадений — уточните запрос, если нужного тикета нет.
Справа столбцы расположены вертикально. Перетаскивайте строки или используйте стрелки вверх/вниз: порядок выбранных столбцов одинаково применяется в CSV и Excel. Чекбоксы включают поля, «Выбрать все»/«Снять выбор» управляют колонками. Заголовки файла английские, значения без перевода. «Скачать Excel»/«Скачать CSV» недоступно без тикетов или выбранных полей и во время загрузки списка. Закрытие формы ничего не изменяет в Azure. Если список не загрузился, повторно откройте экспорт; исходные переданные данные остаются доступны для скачивания после ошибки.

## Azure-выборка
«Импортировать выбранное» открывает подтверждение со списком новых ID и количеством уже имеющихся. Уже импортированные не добавляются повторно. После импорта проверяйте notice/ошибки: просмотр результатов Azure сам по себе не равен локальному импорту.

## Экспорт через ассистента и сворачивание
Попросите «Подготовь Excel с тикетами 123 и 456» — ассистент откроет форму с локальными тикетами. «Добавь ещё 789 в экспорт» дополняет текущий список без повторов, сохраняя формат и порядок столбцов. Если формы ещё нет, создаётся новая. Тикеты из корзины доступны, отсутствующие локально номера отмечаются в ответе; автоматического импорта из Azure или скачивания файла нет. Формат и скачивание выбирает пользователь в форме.
«Свернуть экспорт» освобождает экран: сверху по центру остаётся небольшая панель с количеством тикетов, кнопками «Развернуть экспорт» и «Закрыть экспорт». Можно переходить по страницам, искать задачи и добавлять их через «Экспорт» или ассистента. Повторное открытие добавляет выбранные тикеты к существующему списку; команда ассистента на добавление не разворачивает свёрнутое окно. Закрытие сбрасывает список, сворачивание его сохраняет. Список существует до закрытия, скачивания, перезагрузки страницы или смены заказчика/проекта/подключения Azure; это не сохранённый файл. После скачивания форма закрывается.

В окнах «Отображение» и «Экспорт» включённые столбцы выделены зелёным фоном и рамкой. При перетаскивании линия сверху/снизу показывает вставку перед строкой или после неё. У верхнего/нижнего края списка работает автоматическая прокрутка.
Типы и статусы в списке экспорта используют цвета таблицы. Поиск добавления показывает варианты только после ввода текста; после выбора тикета поле закрывается, возвращая кнопку той же высоты.
Когда экспорт свёрнут, справа от обычной кнопки «Экспорт» появляется зелёная «Добавить в экспорт». Она доступна только при выбранных в таблице тикетах и добавляет их без разворачивания окна. Обычная кнопка «Экспорт» остаётся доступной для открытия формы.

Тикеты из корзины отмечены в списке экспорта отдельным бейджем «В корзине» с центрированным текстом.

Ассистент получает только короткую отметку, что экспорт открыт или свёрнут. Закрытый экспорт не передаётся в контекст модели. Если окно уже существует, ассистент добавляет тикеты через `edit_ticket_export(addIds)`; если закрыто — открывает через `show_ticket_export(ids)`. Списки ID, формат и столбцы автоматически в контекст не загружаются: инструмент `read_selected_tickets` читает их по необходимости из снимка на момент отправки сообщения, по 100 кратких карточек за вызов. По умолчанию карточки содержат ID, название, статус и тип; теги, Azure-теги, приоритет, исполнителя, даты и остальные summary-поля запрашиваются через `fields` только при необходимости. Он также умеет читать выбранные в таблице тикеты (`target=table`); для экспорта используется `target=export`. Это локальное чтение без Azure и без описаний тикетов.

Можно попросить «Оставь номер, название и статус — именно в таком порядке»: ассистент настроит поля открытого экспорта через `edit_ticket_export`, не очищая тикеты. Параметр `columns` задаёт полный упорядоченный набор включённых столбцов; без него выбор полей не меняется. Для добавления одного столбца ассистент может прочитать текущий набор отдельным инструментом. Добавление тикетов всегда объединяется с актуальным списком в интерфейсе.

Редактирование через ассистента доступно только для открытого или свёрнутого экспорта: `edit_ticket_export` принимает `addIds`, `removeIds` и необязательный полный список `columns`. Например, «Убери из экспорта 123 и добавь 456». Остальные тикеты сохраняются; удаление затрагивает только набор экспорта, а не локальные данные или Azure. При пересечении списков удаление имеет приоритет. Свёрнутое окно остаётся свёрнутым. Если окно закрыто, редактирование не создаёт новое; сначала его нужно открыть. Чтение выбора в рамках запроса учитывает отправленные ассистентом изменения; ручные изменения после отправки сообщения будут доступны в следующем запросе.

При открытии и разворачивании фокус устанавливается на окно экспорта, а не на кнопку сворачивания: Enter сразу после открытия ничего не скачивает, не закрывает и не сворачивает. После явного перехода к кнопке клавиатурой Enter по-прежнему активирует её.

Если в списке есть хотя бы один тикет, крестик закрытия (включая свёрнутую панель) и Escape в окне экспорта открывают подтверждение «Закрыть экспорт?». «Продолжить работу» сохраняет список, красная кнопка с крестиком «Закрыть и сбросить список» очищает набор экспорта, не удаляя тикеты из системы. Пустой экспорт закрывается без подтверждения. Сворачивание и закрытие после успешного скачивания не требуют подтверждения.

Перед каждым вызовом редактирования экспорта ассистент должен сначала прочитать текущий набор через `read_selected_tickets(target=export)`, включая повторные изменения в одном запросе и изменение только столбцов. Для изменения состава он дочитывает страницы выбора, сверяет номера, не добавляет уже выбранные тикеты и пропускает изменения без эффекта. Проверка использует снимок на момент сообщения с учётом уже отправленных им правок, а не живое отслеживание ручных изменений в интерфейсе.

«Azure приоритет» доступен отдельным столбцом CSV/Excel (заголовок Azure Priority). Экспортирует число; отсутствие значения — пустая ячейка. Столбец можно включить и переставить вручную или через инструменты ассистента, независимо от Local Priority.

Столбец «Локальный приоритет» (ключ priority, заголовок Local Priority) экспортируется числом без префикса P. Старые настройки столбцов и пресеты сохраняются: ключ поля не изменён.

Поле «Локальный дедлайн» доступно в настройке отображаемых столбцов и в экспорте CSV/Excel. В файле дата представлена в UTC ISO, пустое значение означает отсутствие локального дедлайна. Ассистент может выбирать этот столбец ключом `localDeadline`.

## Режим работы

В режиме «Разработчик» столбец локального поручения отсутствует в таблицах, настройке отображения и экспорте CSV/XLSX. Скрытый столбец не попадает в файл. Его настройки сохраняются для возврата в Lead; команды выбора всех видимых столбцов не изменяют скрытый выбор. Подробности: [Режим работы](work-mode.md).
