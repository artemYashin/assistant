# Фильтры и экспорт тикетов

## Наборы фильтров
Раскройте блок наборов, задайте условия поиска/сортировки и название, нажмите «Сохранить набор». Повторное имя предлагает подтверждение перезаписи. Нажатие набора применяет сохранённые условия; индикатор изменения показывает отклонение от сохранённого набора.
Наборы можно переупорядочить и удалить. Удаление набора не удаляет тикеты. Кнопка сброса снимает выбранный набор, условия и поиск, а не оставляет его выделенным.
## Колонки
Меню столбцов меняет видимость. Разделители позволяют изменять ширину. Настройки таблицы/экспорта — разные наборы: скрытая колонка не обязана исчезнуть из формы экспорта.
## Экспорт
Откройте CSV или Excel. Форма фиксирует снимок выбранных для экспорта тикетов и показывает количество. Выберите поля чекбоксами; «Выбрать все»/«Снять выбор» управляют колонками. Заголовки файла английские, значения без перевода. «Скачать файл» недоступно без строк/полей. Закрытие формы ничего не изменяет в Azure.
## Azure-выборка
«Импортировать выбранное» открывает подтверждение со списком новых ID и количеством уже имеющихся. Уже импортированные не добавляются повторно. После импорта проверяйте notice/ошибки: просмотр результатов Azure сам по себе не равен локальному импорту.
