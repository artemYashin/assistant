# Фильтры и экспорт тикетов

## Наборы фильтров
Раскройте блок наборов, задайте условия поиска/сортировки и название, нажмите «Сохранить набор». Повторное имя предлагает подтверждение перезаписи. Нажатие набора применяет сохранённые условия; индикатор изменения показывает отклонение от сохранённого набора.
Наборы можно переупорядочить и удалить. Удаление набора не удаляет тикеты. Кнопка сброса снимает выбранный набор, условия и поиск, а не оставляет его выделенным.
## Колонки
Меню столбцов меняет видимость. Разделители позволяют изменять ширину. Настройки таблицы/экспорта — разные наборы: скрытая колонка не обязана исчезнуть из формы экспорта.
## Экспорт
Кнопка «Экспорт» открывает общее окно CSV/Excel. Формат выбирается сверху. Слева показаны только отмеченные в таблице тикеты; без выбора окно открывается с пустым списком, а скачивание недоступно. Форма фиксирует снимок выбранных тикетов, не меняя выбор таблицы.
Список прокручивается. Крестик убирает тикет только из экспорта. «Добавить тикет» открывает поиск по номеру или названию среди локальных задач текущего Azure-подключения, включая корзину; Azure не запрашивается. Выберите результат, чтобы добавить его; повторно добавить тот же ID нельзя. Крестик у поиска отменяет добавление. Показаны первые 20 совпадений — уточните запрос, если нужного тикета нет.
Справа столбцы расположены вертикально. Перетаскивайте строки или используйте стрелки вверх/вниз: порядок выбранных столбцов одинаково применяется в CSV и Excel. Чекбоксы включают поля, «Выбрать все»/«Снять выбор» управляют колонками. Заголовки файла английские, значения без перевода. «Скачать Excel»/«Скачать CSV» недоступно без тикетов или выбранных полей и во время загрузки списка. Закрытие формы ничего не изменяет в Azure. Если список не загрузился, повторно откройте экспорт; исходные переданные данные остаются доступны для скачивания после ошибки.

## Azure-выборка
«Импортировать выбранное» открывает подтверждение со списком новых ID и количеством уже имеющихся. Уже импортированные не добавляются повторно. После импорта проверяйте notice/ошибки: просмотр результатов Azure сам по себе не равен локальному импорту.
