# Связанные тикеты PR

## Порядок

1. #номер из описания PR.
2. Дополнительные #номер из названия.
3. Явные связи Work Items в Azure.
4. Тикеты, добавленные вручную в Orbit.
   Повторяющиеся ID объединяются. Порядок — порядок дополнения списка, а не команда игнорировать название при наличии описания. Коммиты и связи между самими тикетами не обходятся.
   Парсер читает целые положительные числовые ID, не имеет ограничения в пять/шесть цифр. UI-обрезание текста не используется как источник парсинга. Но краткий API-ответ списка может закончиться посреди ID: смена приоритета не восстанавливает потерянную цифру.

## Карточки и кнопки

Аккордеон имеет счётчик и иконку информации с этим порядком. Над тикетом указаны источники. Ниже — тип и статус.
«Открыть тикет» показывает деталку. «Не учитывать» сохраняет связь, но исключает тикет из контекста ревью и смены статуса при merge; появляется предупреждение. «Учитывать» возвращает использование.
«Отвязать» удаляет только ручную локальную привязку. Если ID есть в описании, названии или Azure, карточка останется. Для исключения из работы используйте «Не учитывать». Эти действия не меняют связи в Azure.
Локальные исключённые ID остаются видимыми даже если их прежний источник исчез.

## Если тикета нет в локальной базе

Номер всё равно отображается с пометкой недоступности. Активный импорт пытается получить недостающие задачи. Ручная привязка сначала проверяет/импортирует отсутствующую задачу. Завершённый список и его переимпорт обновляют PR и связи, но не импортируют тела всех связанных задач автоматически.
Ошибка доступа или чужой Azure-проект могут оставить карточку только с номером. Не путайте отсутствие загруженного названия с отсутствием самой связи.

В поле «Номер или название тикета» можно найти локальный тикет текущего Azure-подключения по части номера или названия. Поиск оформлен как в попапе экспорта: иконка тикета, номер и название, ниже тип, статус и отметка «В корзине». Подсказку можно выбрать мышью или стрелками и Enter. Подсказки появляются только при непустом запросе; уже связанные тикеты исключены. Выберите результат и нажмите «Привязать локально». Прямой ввод номера (включая #) остаётся доступен для тикета, которого нет в локальном списке. Поиск сам ничего не импортирует и не меняет в Azure.
В списке связанных локальных тикетов доступна кнопка заметок: зелёная, если заметки заполнены. Открывает тот же редактор локальных заметок, что и таблица тикетов; изменения не отправляются в Azure.
