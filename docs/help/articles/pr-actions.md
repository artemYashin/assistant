# Действия PR: ветки, Draft и Abandon

## Ветки и версия
Source — откуда берутся изменения; Target — куда их объединяют. Синие бейджи открывают ветку в Коде репозитория, копирование рядом копирует имя. Версия коммитов и версия diff помогают понять, что именно анализировалось.
«Загрузить source ветку» подготавливает локальный код; недоступна при уже готовой/загружаемой ветке. Готовность Git не означает пройденный CI.
## Создание
«Создать PR» открывает выбор репозитория/веток и описание/название. Селекторы Source и Target ищут актуальные ветки напрямую в Azure: запрос отправляется через 250 мс после изменения строки поиска, а список обновляется при каждом открытии селектора. Во время поиска внутри списка и на кнопке отображается индикатор «Ищем ветки в Azure…»; «Ничего не найдено» появляется только после завершения загрузки. Ответ старого запроса не заменяет результаты нового. Показываются первые 100 веток; если их больше, уточните поиск. Escape при открытом селекторе закрывает только список, сохраняя попап создания PR. Ошибка Azure отображается под селектором; повторное открытие запускает новую попытку. Проверьте source и target до отправки. Это серверное действие Azure, требующее Code Read & write; не создавайте повторно при неясном ответе без проверки.
## Состояние
Mark as Draft переводит в черновик, Unmark as Draft возвращает из него. Abandon закрывает PR без слияния, не удаляет ветку и не объединяет код. Такие действия имеют подтверждение; затем состояние PR перечитывается. Изменение может остановить текущее автоматическое ревью.
Кнопки Set Auto Complete нет. Merge — отдельный процесс со своей формой и проверками.
Завершённая карточка доступна для чтения, diff, коммитов, результата ревью и переимпорта, а не для обычного повторного merge.
