# Банк памяти

## Уровни
Общая, заказчика, проекта, Project Review. Общая/заказчика/проекта попадают в автоматический каталог ассистента как ID, краткое название и ревизия. Полное описание читается по необходимости. Project Review автоматически чату не подмешивается, но он может предлагать туда записи; ревьюер использует выбранные уровни.
Название — 1–2 предложения, максимум 320 символов, без кода. Описание — Markdown с краткими объяснениями, ссылками и небольшими сниппетами. Большой код лучше описывать через функцию/путь, а не копировать целый файл.
## Страница
Банк памяти: мультиселект разделов слева от поиска по названию, найденное количество ниже. Карточки адаптивные, на широком экране два столбца; ID сверху, описание в сворачиваемом аккордеоне.
«Добавить память» открывает форму с выбором области, названием и описанием. «Редактировать» меняет запись вручную. Удаление — confirmation. Refine with AI раскрывает чат и прикрепляет память к следующему сообщению; изменение через ассистента идёт в подтверждения, не применяется сразу.
## Предложения ассистента
Попросите запомнить проверенный факт. Для факта о коде ассистент сначала должен найти подтверждение в репозитории; неоднозначность уточняет, а не сохраняет догадку.
Предпочтительный язык — Настройки → Память, default English. Это язык новых предложений, не перевода всех существующих и не язык ответов чата.
## Экспорт
Export: выберите уровни чекбоксами. Один MD или отдельные MD по разделам; можно включить названия контекста. Режим «Названия в оглавлении, описания в отдельных файлах» создаёт ZIP с оглавлением и details/. После распаковки относительные ссылки ведут к описаниям.
Кнопки скачивания лежат в блоке «Файлы». Пустые разделы не создают содержательный экспорт. Экспорт не меняет память.
