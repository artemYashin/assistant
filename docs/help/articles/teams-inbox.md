# Teams и входящие

В текущем интерфейсе вкладка Microsoft Teams помечена как недоступная/«Скоро», и переход к сообщениям отключён. Наличие серверного кода/инструментов не означает, что подключение готово для пользователя.
Предусмотренный процесс при доступной интеграции: Microsoft Entra tenant/client, подключение Microsoft, выбор наблюдаемых чатов, синхронизация локальных сообщений. Inbox содержит обнаруженные упоминания тикетов, которые можно просмотреть/добавить/отклонить.
Ассистент читает локально синхронизированные Teams-чаты и сообщения. sync_teams_chats — только явная просьба обновить Teams, не история чатов с Orbit.
Отправка: сначала черновик в подтверждения, затем отдельное человеческое подтверждение в интерфейсе. Нельзя считать согласие в чате отправкой.
Azure PAT и GitHub Copilot не дают Teams Chat.Read. Не предлагайте выдать Azure PAT Full access для лечения Teams.
