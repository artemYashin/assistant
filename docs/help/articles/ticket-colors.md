# Типы, статусы и цвета

Настройки → Azure DevOps → Импорт тикетов и оформление. «Сохранить подключение и загрузить типы / статусы» сначала сохраняет подключение, затем читает каталог. Нужен доступ к Azure.
Выберите типы задач и статусы для автоматического импорта Assigned To владельца PAT. Уже добавленные тикеты продолжают обновляться после выхода из фильтра; это не команда удалить их.
Цвета типов и статусов задают визуальную карту в таблицах, деталках и выборе статусов при merge. Изменение цвета не переименовывает Azure-статус, не меняет процесс и не разрешает запрещённый переход.
Каталог кэшируется на сутки. Если Azure-процесс недавно изменился, старый каталог может временно не показывать новый статус. Проверяйте точное имя типа и подключение, а не заменяйте статус локальным тегом.
Локальный приоритет и группировка статусов для разработчиков настраиваются отдельно в контексте проекта.
