# Код репозитория

## Открытие
Пункт кода находится в сайдбаре. Сверху — компактный выбор ветки с поиском, «Проверить», Pull и отладка текущей работы.
Настройки: Заказчики и проекты → Репозиторий → Git. Основная ветка для ассистента независима от ветки, открытой вами в браузере кода.
При настроенной глубине Git от 1 до 9 под названием репозитория показывается жёлтое предупреждение: рекомендуется 0 для полной истории или больше 10, например 100. Указан путь настройки; после сохранения нажмите Pull. Более полная история может сократить повторную загрузку объектов между ветками, но первая загрузка и размер кэша увеличатся. При глубине 0 или от 10 предупреждение не показывается. Значение поступает вместе с данными репозитория, без дополнительного запроса к Azure.
## Просмотр
Слева дерево папок и файлов с иконками типов; ширину панели можно менять разделителем. Выбор файла открывает содержимое с номерами строк и подсветкой. Закрытие файла расширяет список; для файлов доступна поверхностная информация, не обещайте истории создания/автора без отдельного источника.
Файлы читаются из локального Git-кэша микросервиса, а не скачиваются из Azure при каждом клике. Подготовка ветки/Pull/проверка могут обращаться к сети.
## Поиск
Переключатели «По пути»/«По содержимому» с иконками задают режим. Ввод запускает поиск с debounce; результаты появляются под строкой как autocomplete, а не растягивают дерево.
Нажатие результата открывает файл; совпадение по содержимому — нужную строку. Короткий контекст подсвечивается. Поиск по коду literal/ripgrep, не произвольная shell-команда.
Ассистент умеет искать пути, grep, читать диапазоны и при необходимости весь файл. Доступ настраивается в AI Assistant → Code Repository; инструменты не редактируют код.
## Ссылки
Бейдж ветки переходит в нужную ветку; копирование берёт имя. Ссылка на файл/строки содержит ветку и открывает подсветку диапазона. Название кнопки может быть именем файла/функции, но путь внутри ссылки полный.
Отсутствие файла может означать другую ветку, исключение/ограничение формата или неготовый снимок. Уточните branch/path, не делайте вывод «функции нет» из одной пустой выдачи.

## Коммиты текущей ветки
Кнопка «Коммиты» рядом с Pull открывает историю выбранной ветки: сообщение, автор, дата и короткий SHA. История читается из Azure по запросу, не запускает LLM и не докачивает локальную Git-историю; нужна сеть и PAT Code Read. Глубина локального Git (например, 1) список не ограничивает.
Название ветки в заголовке истории — синий бейдж с кнопкой копирования. Нажатие названия закрывает попап и открывает эту ветку в коде репозитория.
Список загружается по 50 записей, «Ещё 50 коммитов» продолжает историю того же SHA, чтобы новые коммиты ветки не сдвигали страницы. «Обновить» начинает загрузку с текущей вершины ветки. Ошибка показывает кнопку повтора.
Нажмите коммит: слева дерево изменённых файлов, справа diff до/после с подсветкой. Здесь нет комментариев к строкам. Первый коммит сравнивается с пустым деревом, merge-коммит — с первым родителем. Действуют общие исключения и лимиты diff проекта; причины пропусков показываются над деревом. Изменения из Azure могут быть новее локального снимка файлов; просмотр коммитов не делает Pull.
