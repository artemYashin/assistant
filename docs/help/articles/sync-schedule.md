# Фоновая синхронизация

Настройки → Azure DevOps → Автоматическая синхронизация: общий интервал и режим «Обновлять всегда»/«По расписанию».
В расписании задаются часы с/до, часовой пояс и дни недели. Одинаковое время означает весь день. Ночной интервал относится к дню начала; без дней автообновление выключено. Вне окна фон приостановлен, ручное обновление доступно.
Общий цикл затрагивает настроенные источники (тикеты, PR). Раздельные кнопки страниц и инструменты sync_tickets/sync_pull_requests работают по запрошенному домену. Синхронизация PR может импортировать недостающие связанные задачи — это побочный этап PR, не полный цикл.
Git имеет отдельную частоту в настройках репозитория, default 30 минут, 0 вручную, с учётом общего разрешённого окна. Не скачивает файл заново на каждое открытие.
При ручной синхронизации ассистентом соответствующие таблицы получают обновление после завершения. Частичные ошибки не означают, что ни одна запись не обновилась.
Сон компьютера/остановленный Docker прерывают возможность фоновой работы. Таймер UI не доказывает, что сеть и сервисы доступны.
