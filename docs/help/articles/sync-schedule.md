# Фоновая синхронизация

Заказчики и проекты → Автоматический импорт → Автоматическая синхронизация: интервал выбранного проекта и режим «Обновлять всегда»/«По расписанию».
В расписании задаются часы с/до и дни недели. Общий часовой пояс перенесён в «Настройки» → «Календарь»; прежнее значение сохраняется. Переключение режима автообновления не меняет пояс. Одинаковое время означает весь день. Ночной интервал относится к дню начала; без дней автообновление выключено. Вне окна фон приостановлен, ручное обновление доступно.
Для каждого проекта отдельно отсчитывается интервал от 1 до 60 минут после завершения предыдущего прохода. Проекты обрабатываются независимо от выбранного в хедере; проверка наступившего времени выполняется примерно раз в 30 секунд. Изменённый интервал применяется при следующем планировании, без перезапуска. В положенное время обновляются тикеты подключения и включённые PR-репозитории этого проекта. При ошибке следующий проход также ждёт интервала; очередь не запускает повторные запросы беспрерывно. Если у нескольких проектов общее Azure-подключение, их фильтры автоимпорта применяются отдельно, но уже прочитанные тикеты в одном проходе не запрашиваются повторно. Раздельные кнопки страниц и инструменты sync_tickets/sync_pull_requests работают по запрошенному домену. Синхронизация PR может импортировать недостающие связанные задачи — это побочный этап PR, не полный цикл.
Git имеет отдельную частоту в настройках репозитория, default 30 минут, 0 вручную, с учётом разрешённого окна своего проекта. Не скачивает файл заново на каждое открытие.
При ручной синхронизации ассистентом соответствующие таблицы получают обновление после завершения. Частичные ошибки не означают, что ни одна запись не обновилась.
Сон компьютера/остановленный Docker прерывают возможность фоновой работы. Таймер UI не доказывает, что сеть и сервисы доступны.

## Обновление существующей установки

Прежнее глобальное расписание и интервал копируются существующим проектам один раз. Уже записанные проектные значения не заменяются. Фильтры автоимпорта, выбранные люди, типы, статусы и история сохраняются. Для изменения выберите проект, настройте расписание и нажмите «Сохранить». Старый клиент без полей расписания не сбрасывает проектные значения. Часовой пояс остаётся общим в «Настройки → Календарь». Настройки уведомлений календаря и их частота не переносятся.
