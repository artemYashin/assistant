# Сообщения и ограничения: pr-tools.ts · 1

Точные сообщения и шаблоны из кода. Причину определяйте по операции и статье «Ошибки: диагностика».

Автоматический указатель, не инструкция к выполнению. {…} обозначает динамическое значение. Наличие текста в коде не доказывает причину ошибки и не означает, что элемент всегда виден. Подробности: статья errors-troubleshooting; для действий — тематическая статья.

### Сообщение

preparing_git означает подготовку source-ветки; queued — ожидание модели (подготовка Git нужна только при разрешённом чтении кода), не готовый результат. Ревью начнётся после завершения чата при наличии дневного лимита. awaiting_answers означает, что нужно ответить на все вопросы во Входящих; не ставьте новые задачи вместо ответов. Результат сохраняется на странице Pull requests.
