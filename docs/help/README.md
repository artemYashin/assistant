# Справка Orbit: сопровождение

articles/ — тематические пользовательские статьи, проверенные по реализации.
generated/ — указатель статических сообщений/ограничений и подписей элементов
интерфейса, полученный AST-разбором TypeScript/JSX и HTTP-ошибок voice Python.
coverage.json — отпечатки исходников для обнаружения изменений после генерации.

Каждая индексируемая MD-статья начинается строкой:
<!-- orbit-help {"id":"stable-id","title":"Короткое название","summary":"Одно-два предложения","keywords":["Azure","токен"]} -->
Далее обычный Markdown. Не меняйте ID без необходимости. Метаданные не содержат
секретов или пользовательских данных. Поиск возвращает только ID, название,
краткое описание и одну выдержку до 240 символов. Чтение статьи — отдельно,
порциями до 10 000 символов. В начале сессии модель видит только две записи
каталога инструментов, не весь индекс и не содержимое статей.

## После изменения функционала
Обновите тематическую статью (пути интерфейса, действия, ограничения и ошибки),
затем npm run docs:generate и npm run docs:check. Команда npm run check
также проверяет свежесть индекса перед TypeScript. Запустите
npx tsx --test tests/help.test.ts и TypeScript-проверку. Генератор ничего не
запрашивает в Azure и не читает базу пользователя.

## Честные границы
Нельзя заранее перечислить все произвольные ответы Azure, Git, Copilot, браузера,
операционной системы и сети. Каталог содержит определённые в исходниках сообщения,
шаблоны и строки ограничений; динамические вставки обозначены {…}.
Некоторые записи — подсказки/лимиты, не ошибки. Условные и вычисляемые подписи
могут отражаться частично: генератор не исполняет приложение. Тематические статьи
объясняют процессы и видимость элементов; каталог помогает искать точный текст.
Не называйте совпадение с шаблоном доказанной причиной сбоя.

Документация соответствует версии приложения, с которой поставляется. При
обновлении контейнера поставляется новый комплект; сервер кэширует файлы справки
на время своего процесса. Пользовательские настройки проверяются отдельными
инструментами только при необходимости, а не подменяются значениями из статьи.
