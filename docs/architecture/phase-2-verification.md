# Проверка второго этапа FSD

27 октября 2026 года. Перенесены 29 модулей моделей, компонентов и экспорта.
Изменения локальные, без коммита и push.

## Проверено

- Сравнение 76 перемещённых/обновлённых исходников и тестов с состоянием перед
  этапом: содержимое вне путей модулей совпадает. Публичные index-файлы проверены
  отдельно типизацией и проверкой архитектуры.
- `npm run check`: архитектурные тесты, граф зависимостей, версии, справка и
  TypeScript проходят.
- `npm run build`: клиент и сервер собираются. ExcelJS остаётся в динамически
  загружаемой части через отдельный публичный вход экспорта. Сохраняется прежнее
  предупреждение Vite о размере chunks.
- `npm test`: 625 тестов, 620 проходят. Те же пять прежних падений, перечисленных
  в `phase-1-verification.md`; новых падений нет.
- Production preview, Playwright с вымышленными API-ответами: открываются
  «Что нового», разработчики, календарь, тикеты, настройки и подтверждения.
  Диалог подтверждения открывается/отменяется, старые browser preferences
  сохраняются, используется прежний ключ просмотренной версии.
- Справка перегенерирована: 223 автоматических статьи, стабильные ID сохранены.

## Совместимость и границы проверки

Серверный код, SQLite, миграции, пользовательские файлы, ключи localStorage и
форматы настроек не менялись. Миграция данных не нужна. Рабочие базы пользователей
для проверки не открывались. Браузерная проверка с mock API не является проверкой
живых интеграций Azure/Copilot. Большие страницы пока остаются переходными.
