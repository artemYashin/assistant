# Проверка пятнадцатого этапа FSD

27 октября 2026 года. Выделен widgets/assistant, в нём объединены панель,
поток ответов/вызовов инструментов и контекст сообщений. legacy-workspace
сократился с 1511 до 725 строк. Без коммита и push.

## Проверено

- Сравнение AST: тела вынесенных компонентов и всех обработчиков Assistant
  совпадают. Отличия композиции — добавленный export, входной prop ticketCard
  и передача прежнего TicketCard из Workspace. Остальные изменения — импорты
  и публичные экспорты.
- `npm run check` проходит: FSD, версия, справка и TypeScript.
- `npm run build` проходит. Прежние предупреждения о крупных chunks и
  аннотациях стороннего zod сохраняются.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  phase-1-verification.md. Новых падений нет.
- Три теста группировки источников справки проходят. Все 224 автоматические
  статьи сохранили ID и содержимое кроме актуализированных ссылок на исходники.
- Playwright с mock API: при перезагрузке восстанавливаются текст ответа и
  выполняющийся инструмент, затем приходят новые части текста и завершение;
  сохраняется итоговая история, новый запуск модели не создаётся.
- В том же браузерном сценарии переключение на проект B скрывает поток A и
  показывает историю B. Возврат к A восстанавливает его поток. Запросы нового
  запуска модели не отправляются, JS-ошибок нет.
- Production preview: основные страницы, сохранённые фильтры тикетов,
  отмена создания/удаления памяти, вкладки настроек и TSX в репозитории проходят
  прежние проверки, browser preferences сохраняются.
- `git diff --check` проходит, серверные исходники не изменены.

## Совместимость

Хранилища, данные, идентификаторы, ключи browser preferences и API не менялись.
Новая миграция не требуется. Тесты используют временные данные и mock API;
живое пользовательское хранилище, Azure и Copilot не затрагиваются. Browser
reconnect проверяет клиентский сценарий с имитацией серверного потока, не
работу внешнего провайдера.

Отдельно в production preview проверена композиция: сохранённое сообщение
с cards открывает настоящий TicketCard, переданный из Workspace. Карточка
с ID 42 отображается до и после перезагрузки; ошибок React нет.
