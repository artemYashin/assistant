# Проверка одиннадцатого этапа FSD

27 октября 2026 года. Перенесены 12 модулей страницы кода, разработчиков,
управления заказчиками/проектами и описания прав Azure. Без коммита и push.

## Проверки

- Сравнение 13 перемещённых/обновлённых исходников с состоянием перед этапом:
  содержимое вне путей модулей совпадает. Публичные входы проверены типизацией.
- `npm run check` и `npm run build` проходят. Предупреждение Vite о размере
  chunks сохраняется.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет.
- Справка перегенерирована: 224 статьи, прежние ID сохранены.
- Playwright, настройки автоматического импорта с mock API: существующие
  420 секунд показаны как 7 минут; изменение на 3 минуты отправляет 180 секунд
  и сохраняет исходное расписание без потери полей.

## Совместимость

Сервер, SQL, файлы пользователя, настройки, ключи storage и правила обработки
контекстов не менялись. Новая миграция данных не нужна. Пользовательская база
не открывалась, живые переименования/удаления контекстов не выполнялись.
Страница разработчиков пока использует прежнюю кнопку копирования из карточки
тикета и тип Settings; зависимости явно описаны в ARCHITECTURE.md.

Production preview с mock API: основные страницы открываются, разработчик
отображается, в репозитории загружаются ветка, дерево и файл demo.tsx.
Worker успешно подсвечивает JSX-атрибуты. JS-ошибок нет; настройки календаря
и ширина чата сохраняются. Реальный Git/Azure для проверки не использовался.
