# Сервисы и чистые проверки

Проверено 27 октября 2026, версия 0.32.2, ветка fsd.

## Исправленные падения

- Два HTTP-теста чата не выбирали проект в настройках, хотя отправляли запрос
  с конкретным контекстом. Фикстуры теперь явно выбирают проект. Проверки отказа
  для чужого проекта, устаревшего Azure source и чужих вложений сохранены.
- Некорректная схема параметров разбиралась снаружи обработчика понятных ошибок.
  Ошибка валидации теперь возвращается как toolFailure с диагностическим ID.
  Проверки режима и запреты операций остаются в силе.
- Тест предложения памяти не передавал обязательное краткое описание summary.
  Обновлён запрос, проверка сохранения предложения осталась.
- Обёртка режима копировала объекты инструментов: пакет сохранял ссылки на
  старые обработчики и обходил позднее добавленную трассировку. Идентичность
  объектов теперь сохраняется; тест проверяет 23 дочерних записи и два внешних
  вызова без дополнительного расходования лимита на дочерние операции.

## React Hooks

Все 48 предупреждений разобраны без отключения правил. Запросы зависят от
значений контекста, стабильных callbacks и memo-значений. Отмена через счётчики
поколений сохранена. Загрузка дерева отбрасывает ответ прежнего запроса даже
после запуска следующего. Head истории коммитов — якорь пагинации, а не причина
повторной загрузки первой страницы. Живой чат использует актуальные обработчики
событий без пересоздания подписки при каждом фрагменте текста. Реактивные входы
подписки (заказчик и проект) остаются явными.

ESLint запускается с --max-warnings 0; rules-of-hooks и exhaustive-deps — ошибки.

## Проверки

- npm run check: ESLint, Prettier, 7 архитектурных тестов и проверка границ FSD,
  версии, актуальность справки, TypeScript.
- npm test: 628 из 628, без пропусков.
- npm run build: frontend и backend собраны. Vite сохраняет прежние сообщения
  о размере бандла и аннотации сторонней зависимости; это не ошибки ESLint.
- Три теста группировки справки проходят; существующие ID статей сохранены.
- Chromium с подменённым API: восстановление текста и инструментов после
  перезагрузки, смена контекста и возврат, без нового запроса модели; числовой
  ввод; пагинация коммитов с закреплённым head; повторная отрисовка родителя не
  перезапускает запросы коммитов и уведомлений.
- docker compose config --quiet проходит. Сборка контейнеров не проверена:
  Docker daemon в этой среде недоступен.

## Совместимость

Это перенос исходников и исправления обработки запросов. SQLite, форматы
настроек, ключи localStorage, каталоги данных и вложений, Compose bind mounts
не менялись. Миграция не требуется. Проверки выполнялись на временных фикстурах,
без обращения к пользовательской базе или реальным Azure/Copilot. Исправленная
трассировка применяется к новым запросам, старые отсутствующие записи не
восстанавливаются.
