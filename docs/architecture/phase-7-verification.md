# Проверка седьмого этапа FSD

27 октября 2026 года. Общий HTTP-транспорт отделён от создания/наблюдения
чат-запуска; перенесены поиск репозитория и панель Git-операций.
Изменения локальные, без коммита и push.

## Проверки

- AST-сравнение 58 обновлённых исходников/тестов вне import declarations:
  исполняемое содержимое сохранено. Отдельно сравнены функции api, setCsrf,
  followChatRun: совпадают. NDJSON-функция совпадает после выделения прежней
  ветки conversation в чатовый адаптер.
- `tests/frontend-transport.test.ts`: проверены единое состояние CSRF для JSON,
  FormData и чата, credentials и отсутствие ручного Content-Type у multipart;
  создание запуска, кодирование run ID, продолжение с курсора и порядок
  251 события, отмена, NDJSON на границах chunks, неполный поток и ошибка API.
- `npm run check` и `npm run build` проходят. Предупреждение о размере chunks
  осталось прежним.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет.
- Справка перегенерирована: 224 статьи. Прежние ID сохранены; добавлен индекс
  отдельного исходника чатового транспорта.
- В браузере из production preview все три worker загружаются и подсвечивают
  TS/TSX. Проверка не использует реальный Azure или пользовательские файлы.

## Совместимость

Все внутренние потребители перенаправлены на нужный транспорт. Общий клиент
не содержит чатовых маршрутов; адаптер чата сохраняет прежний dispatch и
делегирует остальные запросы общему клиенту. Исключения на src/api.ts убраны.
Сервер, SQL, форматы настроек, ключи browser storage, API URL и вложения не
менялись. Миграция данных не нужна. Пользовательская база не открывалась.

Полная оболочка production-сборки с mock API также проверена: основные страницы,
открытие сохранённой заметки, переключение вкладок заметок, подтверждение и
отмена, сохранение предпочтений календаря/чата. JS-ошибок не обнаружено.
