# Проверка девятого этапа FSD

27 октября 2026 года. Перенесены 11 модулей общих компонентов тикетов,
Markdown, цитат и потока ответа; отдельно выделен StatusBadge.
Изменения локальные, без коммита и push.

## Проверки

- AST-сравнение 25 обновлённых исходников/тестов вне импортов: тела сохранены.
  StatusBadge совпадает с извлечённым оригиналом; оставшиеся TicketControls
  совпадают после удаления этой функции и добавления её импорта.
- `npm run check` и `npm run build` проходят. Предупреждение о размере chunks
  осталось прежним. При переносе восстановлен внутренний импорт StatusBadge
  в TicketControls; финальная проверка типов проходит.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет. В suite входят Markdown,
  ссылки/цитаты и общие фрагменты кода.
- Перегенерирована справка: 224 статьи, прежние ID сохранены.
- Production preview, Playwright с mock API: основные страницы и PR открываются,
  diff подсвечивает TSX, список коммитов работает, Escape закрывает диалоги,
  настройки календаря/чата сохраняются, JS-ошибок нет.
- Отдельная браузерная проверка компонентов: цитата показывает #42, текст и
  действие «Показать в тикете»; диалог локального приоритета открывается с
  сохранённым числом 3 и закрывается без изменения. Для dev-сборки mock API
  ограничен /api/, чтобы не перехватывать исходники /src/shared/api/.

## Совместимость

SQL, сервер, API URL, файлы, ключи browser storage и семантика действий не
менялись. Миграция данных не нужна. Живые действия в Azure и пользовательские
базы не использовались. Общие server/chat-stream типы/расчёты пока используются
через одно явно разрешённое исключение; прежние UI-исключения удалены.
