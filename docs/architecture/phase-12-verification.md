# Проверка двенадцатого этапа FSD

27 октября 2026 года. Перенесены 8 модулей памяти, её экспорта, вложений,
истории чатов и контекста сообщения. Без коммита и push.

## Проверки

- Сравнение 13 перемещённых/обновлённых исходников и тестов с состоянием перед
  этапом: содержимое вне путей модулей совпадает. Index-файлы проверены типизацией.
- `npm run check` и `npm run build` проходят. Предупреждение Vite о размере
  chunks сохраняется.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет.
- Справка перегенерирована с сохранением прежних ID.
- Playwright, компоненты вложений и истории с mock API: PNG отображается и
  открывается в превью; Escape закрывает просмотр; PDF отклоняется без потери
  добавленного PNG; удаление вложения убирает строку; история открывается,
  показывает сохранённый чат, подтверждение удаления можно отменить без
  отправки изменяющего запроса. История затем закрывается.

## Совместимость

Логика, форматы файлов, uploadedId, лимиты, scope вложений, освобождение blob URL,
подтверждения и маршруты API сохранены. Сервер, SQL, файлы пользователей и
ключи хранилищ не менялись. Новая миграция данных не нужна. Проверки используют
вымышленные записи и тестовое изображение; реальное удаление чатов, загрузка
в модель или изменения памяти пользователя не выполнялись.

Production preview через полную оболочку с mock API: основные страницы,
предложение памяти с подтверждением/отменой, PR, diff с TSX и коммиты работают;
Escape закрывает диалоги, JS-ошибок нет, browser preferences сохраняются.
