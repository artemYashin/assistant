# Проверка тринадцатого этапа FSD

27 октября 2026 года. Карточка и строка тикета перенесены в widgets/ticket;
рендереры Markdown и редакторы локальных полей размещены в нижнем слое features.
Всего перемещены 11 модулей, включая 9 ранее перенесённых. Без коммита и push.

## Проверки

- AST-сравнение 25 изменённых/перемещённых исходников и тестов: содержимое вне
  импортов и путей модулей сохранено. Публичные index-файлы проверены TypeScript.
- `npm run check` и `npm run build` проходят. Сохраняются предупреждения сборщика
  о крупных chunks и аннотациях стороннего zod.
- `npm test`: 628 тестов, 623 проходят; те же пять известных падений,
  перечисленных в phase-1-verification.md. Новых падений нет.
- Исправлен путь динамического импорта reviewLabelKind в тесте форматирования.
- Справка перегенерирована: 224 автоматические статьи, стабильные ID сохранены.
- Playwright с mock API: цитата показывает номер тикета, текст и действие;
  диалог локального приоритета открывается со значением 3 и закрывается.
- `git diff --check` проходит; серверные исходники не изменены.

## Совместимость

Изменения касаются размещения исходников, импортов и public API. Хранилища,
ключи browser preferences, SQL, идентификаторы записей, содержимое заметок и
файлы вложений не менялись. Миграция данных не нужна. Проверки не используют
живые пользовательские данные или реальные запросы к Azure/Copilot.

Пустой список корневых legacy-модулей не означает завершения FSD: большая
композиция приложения остаётся в app/legacy-workspace.tsx.

Production preview с mock API: основные страницы, подтверждение памяти,
PR/diff/коммиты и просмотр TSX в репозитории открываются без JS-ошибок;
Escape закрывает диалоги, сохранённые browser preferences остаются на месте.
