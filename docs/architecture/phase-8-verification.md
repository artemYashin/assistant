# Проверка восьмого этапа FSD

27 октября 2026 года. Перенесены 15 модулей страницы PR, её диалогов,
общего diff, выбора модели/пользователей Azure и вопросов ревью.
Изменения локальные, без коммита и push.

## Результаты

- Сравнение 20 перемещённых/обновлённых исходников с состоянием перед этапом:
  содержимое вне путей модулей совпадает. Index-файлы проверены типизацией.
- `npm run check` и `npm run build` проходят. Предупреждение Vite о крупных
  chunks сохраняется. Worker diff успешно включён в production-сборку.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет.
- Справка перегенерирована: 224 статьи с сохранёнными ID.
- Playwright на production preview с mock API: основные страницы открываются;
  на странице PR отображается карточка с данными, View Diff показывает дерево
  файлов и TSX с подсвеченными JSX-атрибутами. Диалог закрывается по Escape.
  Список коммитов загружается, показывает тестовый коммит и также закрывается
  по Escape. JS-ошибок нет; настройки календаря/чата сохраняются.

## Совместимость и ограничения

Сервер, SQL, пользовательские файлы и форматы данных не менялись. Кэш diff
остаётся одним Map в том же компоненте, ключи и правила обновления сохранены.
Новая миграция данных не нужна. Живые merge/review/создание PR в Azure не
запускались; браузерная проверка использует только вымышленные данные и diff.
Полная проверка внешних интеграций не заявляется.

Временные зависимости от оставшихся общих компонентов описаны в
ARCHITECTURE.md. Компоненты не дублировались, worker URL перенесён вместе с
точным исключением архитектурного анализатора.
