# Проверка десятого этапа FSD

27 октября 2026 года. Перенесены 9 модулей экспорта, операций с тикетами,
Azure-фильтров, корзины и глобального поиска. Без коммита и push.

## Проверки

- Сравнение 12 перемещённых/обновлённых исходников с состоянием перед этапом:
  содержимое вне путей модулей совпадает. Публичные index-файлы проверены
  типизацией; внутренние импорты не проходят через собственные barrels.
- `npm run check` и `npm run build` проходят. Excel остаётся отдельным
  динамическим chunk; предупреждение о размере chunks осталось прежним.
- `npm test`: 628 тестов, 623 проходят, те же пять прежних падений из
  `phase-1-verification.md`; новых падений нет.
- Перегенерирована справка: 224 статьи, прежние ID сохранены.
- Playwright, компонент экспорта с mock API: копирование Markdown и HTML/plain
  таблицы, обработка отказа clipboard без потери черновика, Enter без скачивания,
  сохранение имени при сворачивании/добавлении тикета, изменение расширения на CSV,
  фактическое скачивание с заданным именем, новый черновик с пустым именем.

## Совместимость

Singleton контекста экспорта и его события остаются в одном модуле. Команды
ассистента используют тот же публичный UI-вход, что и оболочка. Настройки
столбцов, фильтры, выделение, ключи и API URL сохранены. Сервер, схемы, файлы
пользователей и данные не менялись; новая миграция не нужна.

Три переходные зависимости описаны в ARCHITECTURE.md. Карточка и строка тикета
пока остаются для отдельного этапа. Тесты используют вымышленные тикеты;
изменения статуса/исполнителя в живом Azure не выполнялись.

Production preview через полную оболочку: основные страницы открываются,
экспорт запускается кнопкой таблицы, сворачивается, разворачивается и закрывается.
JS-ошибок нет, предпочтения календаря/чата сохраняются. API в проверке mock.
