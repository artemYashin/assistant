# Проверка пятого этапа FSD

27 октября 2026 года. Перенесены 10 модулей: календарь с временной сеткой,
уведомления, настройки, расписание, завершение итерации, использование LLM
и блоки обзора. Изменения локальные, без коммита и push.

## Автоматические проверки

- Сравнение 12 перемещённых/обновлённых исходников с состоянием перед этапом:
  содержимое вне путей модулей совпадает. Новые index-файлы проверены типизацией.
- `npm run check` и `npm run build` проходят. Предупреждение Vite о размере
  chunks осталось прежним.
- `npm test`: 625 тестов, 620 проходят, те же пять прежних падений, перечисленные
  в `phase-1-verification.md`; новых падений нет.
- Справка перегенерирована: 223 прежние статьи, стабильные ID сохранены.

## Совместимость

Сервер, SQL, пользовательские файлы и форматы данных не менялись. Ключи
localStorage, API, события, интервалы обновления, подтверждения и расчёты
календаря сохранены. Новая миграция данных не нужна. Рабочая база пользователей
не открывалась. Общие серверные расчёты не дублируются; переходные зависимости
описаны в ARCHITECTURE.md.

## Браузер

Playwright на production preview с вымышленными API-ответами проверил страницы
обновлений, разработчиков, календаря, тикетов, настроек, подтверждений и
использования LLM. Проверка с заполненным напоминанием:

- открытие панели уведомлений и переход из неё в деталку напоминания;
- отображение сохранённого названия в редакторе;
- открытие подтверждения завершения, отмена и возвращение в деталку;
- закрытие деталки, открытие и закрытие формы нового напоминания;
- отсутствие JS-ошибок и сохранение прежних настроек календаря/ширины чата.

В первой версии тестового сценария кнопка «Отмена» находилась неоднозначно
в двух диалогах; селектор уточнён до диалога подтверждения, приложение для
этого не менялось. Живые Azure/Copilot в этой проверке не использовались.
