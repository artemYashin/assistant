# Проверка четырнадцатого этапа FSD

27 октября 2026 года. Из app/legacy-workspace.tsx выделены страницы тикетов,
памяти и настроек, LoginCode и четыре общих UI-компонента. Файл сократился
с 3048 до 1511 строк. Без коммита и push.

## Проверено

- AST-сравнение всех 15 прежних верхнеуровневых объявлений: тела совпадают,
  за исключением добавленного export у вынесенных компонентов. Импорты
  подобраны по ссылкам на символы TypeScript, не копированием всего списка.
- `npm run check`: правила FSD, версия, свежесть справки и TypeScript проходят.
- `npm run build`: клиентская и серверная сборка проходят. Предупреждения
  о крупных chunks и аннотациях стороннего zod сохраняются.
- `npm test`: 628 тестов, 623 проходят, пять прежних падений из
  phase-1-verification.md. Новых падений нет; полный набор не зелёный.
- Три теста scripts/help-source-groups.test.mjs проходят: порядок объявлений
  и реальные строки источников, включение новых объявлений, ошибки при
  отсутствующих/дублированных записях манифеста.
- Все 224 автоматические статьи сохранили ID и содержимое, кроме ссылок на
  исходники. Fingerprints охватывают 347 файлов. Authored help не меняет
  пользовательских инструкций, поскольку поведение осталось прежним.
- Production preview с mock API: тикет с существующими полями отображается;
  поисковый фильтр сохраняется после перезагрузки; сохранённая память видна;
  создание и удаление памяти можно отменить; все восемь вкладок настроек
  переключаются. Основные страницы, подтверждение памяти и TSX в репозитории
  работают без JS-ошибок, прежние browser preferences сохраняются.
- `git diff --check` проходит. Серверные исходники не изменены.

## Совместимость и границы

Форматы данных, ключи настроек/фильтров, идентификаторы, API и файлы вложений
не менялись. Состояние страниц осталось внутри тех же React-компонентов;
порядок хуков сохранён. Миграция данных не нужна. Проверки выполнялись
с вымышленными API-ответами и временными тестовыми данными, без работы
с пользовательским хранилищем и без обращений к Azure/Copilot.

Workspace и Assistant остаются в временной сборке; их дальнейшее разделение
нужно проверять отдельно, особенно потоковые ответы и смену контекста.
