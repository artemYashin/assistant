# Проверка третьего этапа FSD

27 октября 2026 года. Перенесён 21 модуль: фильтры и столбцы тикетов,
выделение/просмотр, режим работы, выбранный контекст и голосовой ввод.
Изменения остаются локальными, без коммита и push.

## Результаты

- Сравнение 44 перемещённых/обновлённых исходников и тестов с состоянием перед
  этапом: содержимое вне путей модулей совпадает. Новые публичные входы проверены
  типизацией и анализом архитектурных зависимостей.
- `npm run check` проходит: архитектурные тесты, зависимости, версии, справка,
  TypeScript. Генерация сохраняет 223 прежние статьи справки и их ID.
- `npm run build` проходит. Предупреждение о крупных chunks остаётся прежним.
- `npm test`: 625 тестов, 620 проходят, те же пять прежних падений, перечисленных
  в `phase-1-verification.md`. Новых падений нет.
- Playwright на production preview с вымышленными API-ответами проверил страницы
  обновлений, разработчиков, календаря, тикетов, настроек и подтверждений.
- В браузере предварительно сохранённые фильтры тикетов и выключенный столбец
  «Azure приоритет» сохранились после перезагрузки. Диалог «Отображение столбцов»
  открывается и закрывается по Escape. «Локальное поручение» доступно в Lead и
  скрывается в Developer. Настройки календаря и ширина чата также сохранились.

## Данные и ограничения

Сервер, SQL, файлы вложений и форматы пользовательских настроек не менялись.
Существующие ключи localStorage и совместимое чтение старых фильтров сохранены.
Новая миграция данных не нужна. Рабочие базы пользователей не открывались.
Проверка с mock API не проверяет живой Azure/Copilot или распознавание речи
микрофоном. Вызовы голосового ввода, сочетания и обработчики событий перенесены
без изменений; автоматические проверки горячих клавиш входят в общий suite.

Шесть временных зависимостей на старый HTTP-клиент и общие серверные правила
явно описаны в ARCHITECTURE.md и разрешены точечно. Большие страницы остаются
переходными и требуют следующих этапов.
