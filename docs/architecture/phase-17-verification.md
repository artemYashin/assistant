# Проверка семнадцатого этапа FSD

27 октября 2026 года. JSX Workspace разделён на сайдбар, хедер, область страниц
и блоки обзора, pull requests, тикетов и подтверждений. Без коммита и push.

## Проверено

- После обратной подстановки возвращаемого JSX новых компонентов исходная
  структура совпадает с прежним Workspace. Сравнение исключает только пустые
  JSX-пробелы и добавленные фрагменты без DOM-обёрток; условия, атрибуты,
  callbacks и ключи компонентов сохраняются.
- Props типизированы через Pick от возвращаемого состояния useWorkspace;
  состояние не копируется и hook не вызывается из новых компонентов.
- `npm run check` и `npm run build` проходят. Предупреждения о крупных chunks
  и аннотациях стороннего zod сохраняются.
- `npm test`: 628 тестов, 623 проходят, те же пять известных падений из
  phase-1-verification.md. Новых падений нет.
- Все 224 автоматические статьи сохранили ID и содержимое, кроме ссылок на
  актуальные файлы/строки. Покрытие справки — 357 исходников.
- `git diff --check` проходит; серверные исходники не изменены.

## Совместимость

Новых DOM-контейнеров, состояний, API или хранилищ нет. Экспорт остаётся в общей
области страниц, ассистент — рядом с main. Сохранённые фильтры, привязки контекста,
ключи компонентов и пользовательские данные не преобразуются. Миграция не нужна.
Проверки используют временные данные и mock API, без реальных Azure/Copilot.

## Браузерные сценарии

Production preview с mock API:

- Основные страницы, заполненная таблица тикетов и сохранение поиска после
  перезагрузки; отмена создания/удаления памяти; все вкладки настроек.
- Обзор, три вкладки тикетов и три вкладки PR; корректный aria-current;
  экран неизвестного маршрута; открытие/сворачивание чата из хедера.
- Экспорт открывается, сворачивается, восстанавливается и закрывается.
- Задержанный ответ предыдущего проекта не подменяет память нового проекта.
  Выбранный проект и свёрнутый сайдбар восстанавливаются после перезагрузки.
- Три теста группировки исходников справки проходят.

В этих сценариях ошибок JavaScript не обнаружено. Проверки подтверждают
клиентскую композицию с имитацией API, не работу внешних сервисов.
